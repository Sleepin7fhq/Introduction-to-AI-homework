怎么看这个程序
================

第一步：双击「1-启动」
  等 2～4 秒，黑框里出现：
      IPC 服务已启动: 127.0.0.1:8765
  这个黑框不要关。

第二步：双击「2-看结果」
  每 5 秒显示一段：
      [11:30:00] 第 12 段: 游戏外放   置信度 0.619   音量 -17.0 dBFS   细分标签: Gunshot, gunfire
                 累计: 大声喧哗 0s | 正常音量 0s | 游戏外放 5s | 正常交谈 0s

第三步（可选）：想从 0 开始
  双击「3-清零」。

它怎么判断（不是分贝仪）
------------------------
  1. 音量 ≤ -45 dBFS：一般先算「正常音量」。
     但如果是枪声/爆炸/游戏音乐标签，即使音量低到 -50 dBFS，
     也仍然判「游戏外放」（这是最新加的低音量例外）。
  2. 枪声/爆炸/游戏音乐/电子乐标签：
       Gunshot, gunfire / Machine gun / Explosion / Artillery fire /
       Video game music / Electronic music / Drum machine ...
     只要概率足够，就判「游戏外放」，不会因为音乐概率更大而被吃掉。
  3. 模型判为“说话”，且音量 ≥ -22 dBFS：判「大声喧哗」。
  4. 说话但音量低：判「正常交谈」。
  5. 其它（钢琴、蒸汽哨等）：未分类。

放枪声却识别不到？先看“音量”
------------------------------
  结果窗口每行都有 音量 xx.x dBFS：
    -50 以上：程序能听到，应该能识别；
    -55 以下：麦克风几乎没收到，AI 也听不到，无法识别。

  如果音量很低，按顺序检查：
  1. 枪声是不是从耳机里出的？耳机的声音，笔记本麦克风基本听不到。
     改成扬声器外放，或者把耳机音量调大、耳机靠近麦克风。
  2. 如果戴着 HyperX 耳机，把 Windows 输入设备切成
     「耳机式麦克风 (HyperX ...)」，别用笔记本阵列。
  3. 声音设置 → 输入 → 麦克风阵列 → 属性 → 级别，
     把「麦克风加强」调到 +20～+30 dB。
  4. 还不行，就在 声音设置 → 录制 里启用「立体声混音」并设为默认，
     这样程序直接听电脑里播放的声音（仅用于测试）。

打游戏测试
----------
  开着 1-启动 和 2-看结果，进游戏开几枪。
  细分标签出现 Gunshot, gunfire / Machine gun / Explosion，
  类别是「游戏外放」，就说明 AI 在按声音内容分类。

  如果枪声仍是“未分类”，把那一行的
  “音量”和“细分标签”发我，我再调。

停止：两个窗口都关掉。
目录里其它东西（dist、build、kernel、models、scripts）不要动。
换电脑：整个「项目开发」文件夹一起拷，先 1-启动，再 2-看结果。
