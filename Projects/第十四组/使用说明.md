# 旋律自动配伴奏（路线 A）使用说明

版本 v4.3 · 2026-11-21（十三种织体 + 多层叠加 + 鼓轨 + 副旋律 + 可视化界面 + 混响引擎） · 自带 Python 运行时与音色库，复制整个文件夹即可运行。

---

## 0. 30 秒上手

1. 打开本文件夹，找到 **`run_cli.cmd`**。
2. 把你的 `.mid` 文件**拖到 `run_cli.cmd` 上**，松手。
3. 在你的 MIDI 同目录下会生成三个文件：

```
我的旋律_accomp.mid          带伴奏的 MIDI
我的旋律_accomp.wav          双击试听
我的旋律_accomp_chords.txt   每小节和弦谱
```

窗口里会显示调性、和弦谱、V7/副属数量与冲突率，按任意键关闭。

## 0.1 可视化界面（推荐）

双击 **`run_gui.cmd`**，或把 MIDI 拖到它上面（可直接预填文件）。

![界面截图](界面截图.png)

界面里可以：

1. 点“浏览…”选旋律（`.mid` / `.midi` / `.xml` / `.musicxml`）
2. 点 **“自动配置”**：分析旋律并自动填好下面所有参数（也可以跳过，手动选）
3. 用下拉框选**织体**（十三种）、**和声节奏**（1/2 和弦每小节）、**调性**（自动或指定）
4. 选**和声模式**（rich/simple）、**音色组**（piano/strings/band）、**人性化**（off/light/strong）
5. 勾选**副旋律**、**鼓轨**、**自动转调**、**乐句加花**、**表情**、**导出分轨**，选**混响**（无/轻/中/大厅）、**算法**（ir / freeverb）、**厅堂**（无/hall/opera/church）和**音源**（fluid/musescore/generaluser）；**叠层1/叠层2** 可选额外织体，**乐器1/乐器2** 可指定每层乐器，**叠层八度** 选 -12/0/12；**平衡** 选 orchestral/pop/flat
6. 点“生成伴奏”，右侧会画出**钢琴卷帘**（蓝=旋律、绿=和弦、橙=低音、紫=副旋律、灰=鼓）
7. 用“▶ 播放 / ■ 停止”试听，或“打开 WAV / 打开输出目录”

生成逻辑与命令行完全一致；界面只是把参数拼给同一套 `route_a` 模块。

### 自动配置（v3.5）

命令行加 `--auto`，界面点“自动配置”，都会先分析旋律再给整套参数：

| 分析 | 判断 | 选择 | IR | 音源 |
| --- | --- | --- | --- | --- |
| 拍号 | 3/4 | `waltz` + 弦乐 + hall | `hall` | `musescore` |
| 速度/密度 | ≥122 BPM 且 ≥1.1 音/拍 | `sync`/`pop` + 小乐队 + 鼓 + pop 平衡 | `opera` | `generaluser` |
| 速度/时值 | ≤70 BPM 或平均时值 ≥1.6 拍 | `pad` + 弦乐 + hall + 副旋律 + 钢琴琶音叠层 | `church` | `musescore` |
| 密度 | ≤0.75 音/拍 | `block` + 弦乐 + hall + 副旋律 | `church` | `musescore` |
| 密度 | ≥1.8 音/拍 | `alberti` + 钢琴 + 弦乐铺底 | `hall` | `musescore` |
| 其他 | 中速 | `arpeggio` + 钢琴 + 弦乐铺底 + 中混响 | `hall` | `musescore` |

半音化低时用 `simple` 和声，高时用 `rich`；自动配置会覆盖手动参数，生成后仍可再改。

```powershell
.\run_cli.cmd 我的旋律.mid --auto
```

> 双击没反应时，改用 `run_gui_debug.cmd`，会保留控制台并显示报错。

## 2. 拖拽用法

- 支持 `.mid`、`.midi`、`.xml`、`.musicxml`。
- 多轨 MIDI 会默认挑“音区最高、音符较多”的轨；挑错了看第 7 节。
- 输出默认写在**输入文件旁边**。
- 想统一放到别处，用命令行加 `-o`（见第 3 节）。

## 3. 命令行用法

在文件夹空白处 **Shift + 右键 → 在此处打开 PowerShell 窗口**：

```powershell
# 最基本：block 织体，自动判调，同时出 MIDI 和 WAV
.\run_cli.cmd 我的旋律.mid

# 十三种织体任选
.\run_cli.cmd 我的旋律.mid --style alberti
.\run_cli.cmd 我的旋律.mid --style arpeggio
.\run_cli.cmd 我的旋律.mid --style waltz
.\run_cli.cmd 我的旋律.mid --style pop
.\run_cli.cmd 我的旋律.mid --style pad
.\run_cli.cmd 我的旋律.mid --style bossa
.\run_cli.cmd 我的旋律.mid --style stride
.\run_cli.cmd 我的旋律.mid --style march
.\run_cli.cmd 我的旋律.mid --style guitar
.\run_cli.cmd 我的旋律.mid --style arp16
.\run_cli.cmd 我的旋律.mid --style sync
.\run_cli.cmd 我的旋律.mid --style scale

# 旋律密集时，一小节两个和弦
.\run_cli.cmd 我的旋律.mid --chords-per-bar 2

# 自动判调错了，手动指定
.\run_cli.cmd 卡农.mid --key "D major"
.\run_cli.cmd 小调歌.mid --key "Am"

# 多轨 MIDI：先看有哪些轨，再指定
.\run_cli.cmd 乐队.mid --list-parts
.\run_cli.cmd 乐队.mid --track 1

# 指定输出位置（WAV 默认跟 MIDI 同目录）
.\run_cli.cmd 我的旋律.mid -o output\成品.mid

# 只要 MIDI，不渲染 WAV（最快）
.\run_cli.cmd 我的旋律.mid --no-wav

# 关闭自动转调，回到“单一调性”的和声
.\run_cli.cmd 我的旋律.mid --no-modulate

# 加一轨副旋律（对位内声部，通道 4）
.\run_cli.cmd 我的旋律.mid --counter

# 加一轨 GM 鼓（通道 10）
.\run_cli.cmd 我的旋律.mid --drums

# 编成“五轨小乐队”：旋律 + 和弦 + 低音 + 副旋律 + 鼓
.\run_cli.cmd 我的旋律.mid --style pop --counter --drums
.\run_cli.cmd 我的旋律.mid --drums --drum-pattern bossa

# 加混响（WAV 会在末尾多出混响尾音）
.\run_cli.cmd 我的旋律.mid --style pad --reverb medium
.\run_cli.cmd 我的旋律.mid --style pad --reverb hall --reverb-mix 0.6
.\run_cli.cmd 我的旋律.mid --style pad --reverb hall --reverb-engine freeverb

# 换音色库（任意 SF2/SF3）
.\run_cli.cmd 我的旋律.mid --soundfont "D:\Samples\Orchestral.sf2"

# 圣咏/合唱：简单和声 + 弦乐 + 轻人性化
.\run_cli.cmd 我的旋律.mid --harmony simple --ensemble strings --humanize light

# 小乐队：流行和声 + 乐队音色 + 强人性化
.\run_cli.cmd 我的旋律.mid --harmony rich --ensemble band --humanize strong
```

| `--no-variation` | 关 | 关闭乐句末尾加花 |
| `--no-avoid` | 关 | 关闭伴奏避让旋律（默认开启） |

## 4. 十三种织体

| 名称 | 音型 | 适用 |
| --- | --- | --- |
| `block` | 柱式和弦，整小节铺底 | 慢歌、chorale、最稳 |
| `alberti` | 低音-高-中-高，八分音符 | 古典钢琴、儿歌 |
| `arpeggio` | 低音起，和弦音上行再折回 | 流行抒情、叙事 |
| `waltz` | 低音-和弦-和弦（3/4） | 圆舞曲；4/4 会自动退化为 block |
| `pop` | 低音每拍 + 反拍短和弦 | 流行、轻快 |
| `pad` | 长音持续，力度较低 | 弦乐/合成器铺底 |
| `bossa` | 低音 1、3 拍 + 每拍后半拍切分和弦 | 波萨诺瓦、轻爵士 |
| `stride` | 强拍低音（八度加倍）+ 弱拍和弦 | 跨步钢琴、复古爵士；3/4 退化为 waltz |
| `march` | 低音-和弦交替、强拍加重、句尾弱起和弦 | 进行曲、队列、儿歌 |
| `guitar` | 每两拍低音 + 八分音符低-中-高-中 | 民谣指弹 |
| `arp16` | 十六分宽琶音，跨两个八度，低音每两拍 | 电影感、抒情高潮 |
| `sync` | 3+3+2 切分重音，低音 1、3 拍 | 流行、R&B、拉丁 |
| `scale` | 八分音符音阶跑动，强拍锚在和弦音 | 歌舞片、古典、过门 |

### 多层伴奏（叠加）

织体本身不矛盾：它们只是同一套和声的不同实现。默认只让一种织体占用和弦轨；
要用“钢琴琶音 + 弦乐铺底”这种组合，用 `--layer` 叠加，最多两层：

```powershell
# 主织体 arpeggio，再叠一层 pad（弦乐长音）
.\run_cli.cmd 我的旋律.mid --style arpeggio --layer pad

# 两层叠加：pad + guitar
# 两层叠加：pad + guitar，并指定乐器
.\run_cli.cmd 我的旋律.mid --style sync --layer pad:strings --layer guitar:guitar

# 乐器化叠层：弦乐铺底 + 长笛对位
.\run_cli.cmd 我的旋律.mid --style arpeggio --layer pad:strings --layer arpeggio:flute

# 叠层整体降八度（0 最稳；-12 靠近低音、+12 靠近旋律，按需用）
.\run_cli.cmd 我的旋律.mid --style arpeggio --layer pad --layer-octave -12
```

界面同样支持：左侧“叠层1 / 叠层2”选织体，“乐器1 / 乐器2”选乐器，“叠层八度”选 -12/0/12，点生成即可。

规则（默认全部生效，按配器原则约束）：

- 叠层只取**和弦音**，低音仍由主织体负责，不会两条低音打架。
- **每层只取 2 个和弦音**：`pad`/`block` 取根音+五度，`sync`/`pop` 取根音+三度，`arpeggio`/`scale` 取三度+七度。
- **音区分工**：铺底 43–55、切分 52–64、流动 58–70；叠层会自动让开旋律音区，必要时整体八度折叠回自己的音区。
- **避让旋律**：与主旋律同度/小二度同时发声的音会被直接丢弃。
- **节奏互补**：主织体与叠层同为密集型时，叠层隔一个音留一个，保留音型轮廓但不抢拍。
- **乐器化生成**（v3.1）：音域按乐器折叠；长笛/小号/贝斯只出一个音；弦乐/人声把流动音型改成持续长音；吉他/钢琴保留拨奏并把时值截短。
- **响度补偿**（v3.4）：钢琴/电钢/吉他/长笛在叠层里自动 +2–3dB（CC7 118 vs 弦乐 79），避免被铺底盖住。
- 每层一条独立轨道：通道 5、6（内部 4、5）；不指定乐器时，`pad`/`block` 默认弦乐，其余按织体默认。
- 叠层力度会自动压低 6–10，让主织体在前。
- 两种以上密集音型叠加时仍会提示“容易浑浊”；推荐一密一疏，如 `pad + arpeggio`、`pad + sync`、`block + guitar`。

### 音量平衡（mixer，v3.3）

`--balance` 用 **MIDI CC7（channel volume）** 给每条轨设基准音量，而不是只改音符力度：
力度会同时改变音色（砸得越重越亮），CC7 只改响度，更接近配器里的“声部比例”。

| 轨道 | `orchestral` | `pop` | CC7（orchestral） |
| --- | --- | --- | --- |
| 旋律 | 1.00 | 1.00 | 127 |
| 副旋律 | 0.72 | 0.65 | 91 |
| 和弦 | 0.62 | 0.72 | 79 |
| 低音 | 0.80 | 0.90 | 102 |
| 叠层 | 0.62 | 0.68 | 79 |
| 鼓 | 0.78 | 0.92 | 99 |

效果：旋律始终在最前，副旋律次之，和弦/铺底退到背景，低音托底；`flat` 全部 1.0，
用于自己进 DAW 重新做混音。

```powershell
# 配器平衡（默认）
.\run_cli.cmd 我的旋律.mid --style arpeggio --layer pad:strings --counter

# 流行平衡：低音和鼓更突出
.\run_cli.cmd 我的旋律.mid --style sync --drums --balance pop

# 平直：所有轨 127，留给 DAW 混音
.\run_cli.cmd 我的旋律.mid --balance flat
```

界面里对应“平衡”下拉框。

### 表情自动化（v3.8）

`--expression light|strong`（默认 light）每 0.5 拍采样一次旋律能量（音数 + 音高），
给每条轨写 **CC11 表情曲线**，不是整首一个音量：

| 轨道 | 跟随方式 |
| --- | --- |
| 和弦 | 跟旋律密度，强拍略抬 |
| 低音 | 稳定托底，只做轻微乐句弧 |
| 副旋律 | 旋律越空越出来 |
| 铺底层（弦乐/人声/管风琴） | 跟乐句弧，慢慢呼吸 |
| 拨奏层（钢琴/吉他） | 跟旋律密度，短促响应 |
| 鼓 | 几乎不动 |

CC11 与 CC7 独立：CC7 定声部比例，CC11 做过程中的起伏。`light` 幅度小，`strong` 更明显，
`off` 完全平直。界面勾选 **“表情”**。

实测《欢乐颂》：和弦 CC11 在 86–108 之间起伏，低音 98–104，副旋律 70–112。

### 分轨、乐句加花、避让（v3.6）

- **`--stems` / 界面“导出分轨”**：除了总混音，再导出每轨干声：
  `<名字>_stems/Melody.wav`、`Chords.wav`、`Bass.wav`、`Counter.wav`、`Layer1.wav`、`Drums.wav`。
  分轨**不加混响**，方便进 DAW 自己加空间。
- **乐句加花**（默认开）：每 4 小节句尾最后一拍加 4 个十六分和弦音填充，避免整首一个循环；
  `--no-variation` 关闭。
- **伴奏避让旋律**（默认开）：与旋律同度/小二度的伴奏音先试八度移位，仍冲突才丢弃；
  `--no-avoid` 关闭。
- **调性低置信度提示**：自动识别置信度低于 0.55 时，命令行会打印候选调，提示用 `--key` 指定。

```powershell
# 分轨 + 加花

# 关闭加花/避让，回到旧行为
.\run_cli.cmd 我的旋律.mid --no-variation --no-avoid
```

## 5. 和声特性（v2 改造）

- **V7 使用率提高**：终止处 V7→I 额外加分，旋律含七音时优先 V7。
- **副属和弦**：V7/V、V7/vi、V7/ii、V7/iii（小调为 V7/iv、V7/VI、V7/V），
  未解决会重罚，所以通常出现在真正需要的地方（如 D7→G7、E7→Am）。
- **自动转调**：只在尾部乐句、且满足“尾段音集完全落入新调、出现新调导音、
  末音是新调主音、且含当前调之外的音”时才触发；默认只考虑属方向与下属方向。
  不想要就加 `--no-modulate`。
- 和弦谱里会直接显示 `G7`、`D7`、`E7`，不再是看不出七音的三和弦写法。

### 低音线：转位与经过音（v3.7）

低音不再永远踩根音：

- **转位**：在根音 / 三音 / 五音（36–52）里选，优先靠近前一个低音；
  跳进超过五度会被扣分，终止和第一小节强制回根音。
- **经过音**：相邻低音相差 1–2 个半音、且中间有空隙时，在下一个低音前补一个级进音。
  经过音同样避让旋律，且不会和已有低音同拍。
- 输出日志会多一行：

```
低音    : 转位 1 处，经过音 3 个
```

实测《欢乐颂》1 处转位、3 个经过音；《小星星》5 处转位、8 个经过音。
这一层没有开关，默认生效；不想要只能改代码里的 `bass.py`。

### 调性判定与旋律提取（v4.2）

**调性**：在 music21 的基础上加了两条证据：

- 关系大小调：首尾都落在关系大调主音上时翻转；
- 调号：小调曲子的调号与关系大调一致、且末音不是小调主音时，判为关系大调。
  Canon 从 `B minor` 修正为 `D major`，11 首示例现在 **11/11** 正确。

**旋律提取**：单轨钢琴谱不再“每个和弦取最高音”，而是按起始时间分组后用动态规划选一条线：

- 高音优先、级进优先、长音优先；
- 每个起点只留一个音，和弦/分解伴奏被折叠成单声部。

ASAP 实测平均音程从 3.56 降到 2.63 半音，大跳比例从 1% 降到 0%；《欢乐颂》这类单声部旋律保持原样。

更新后的基准：

| 基准 | 结果 |
| --- | --- |
| 11 首示例 | 调性 11/11，终止 11/11 |
| 巴赫众赞歌 20 首 | 调性 80%，终止 100%，Jaccard 0.397 |
| ASAP 20 首 | 调性置信度 0.83，冲突 35.7%，7.5s/首 |

### 低音/和声骨架（v4.3）

对整份谱子（不只是旋律）按拍采样：

- **低音线**：每拍的最低音，连续同音合并成长音；
- **和弦骨架**：每拍所有发声音级，按大三/小三模板推根音；
- **直方图**：根音、低音按拍数加权，用于看调性/和声重心；
- **终止**：最后一拍的低音与根音。

单声部文件（如 Canon 的旋律轨）会标记为“单声部输入”，不做假和声分析。
多声部文件在命令行/界面日志里会多一行：

```
骨架    : 106 段，根音吻合 26%
```

“根音吻合”是**我们生成的和弦根音**与骨架根音的一致率，用来诊断编配差异，不是对错。
巴赫赋格实测 26%——说明自动配的流行/古典和声与赋格的流动低音本来就不是一回事。

骨架还给调性置信度加 0.05（终止根音=主音时），但**不直接改调**，避免被半终止带偏。

## 6. 输出文件与 MIDI 通道

| 文件 | 内容 |
| --- | --- |
| `_accomp.mid` | 三轨或五轨 MIDI（副旋律/鼓按开关加入） |
| `_accomp.wav` | 44.1 kHz、双声道、峰值归一化到 0.9 |
| `_accomp_chords.txt` | `Key: ...` 加一行 `C | G7 | Am | ...` |

MIDI 通道分配（按大家习惯的 1 起编号）：

| 轨道 | 通道 | 音色 | 内容 |
| --- | --- | --- | --- |
| Melody | **1** | 钢琴 (program 0) | 原旋律 |
| Chords | **2** | 钢琴 (program 0) | 和弦织体 |
| Bass | **3** | 贝斯 (program 32) | 低音 |
| Counter | **4** | 钢琴 (program 0) | 副旋律（`--counter` 时才有） |
| Layer 1 | **5** | 弦乐/钢琴 | 第一层叠加（`--layer` 时才有） |
| Layer 2 | **6** | 弦乐/钢琴 | 第二层叠加（`--layer` 两次时才有） |
| Drums | **10** | GM 打击乐 | 鼓（`--drums` 时才有；通道 10 不放 program change） |

> 程序内部通道号是 0/1/2/3/9，DAW 里显示为 1/2/3/4/10。

把 `_accomp.mid` 拖进 DAW / MuseScore 即可换音色、单独调各轨音量。鼓太吵就在 DAW 里把第 10 轨拉低。

**鼓轨**：`auto` 会按织体选鼓型（bossa→bossa，waltz/3/4→waltz，pad/block/alberti/stride→ballad，其余→pop）；
每 4 小节句首加吊镲，4/4 句尾加两个十六分军鼓过门。

**副旋律**：只用和弦音，音域 G3–G4，每小节 2–3 个音；与主旋律同时发声时避开同度/小二度，
句尾落在主和弦的根音或三音上。

## 7. 常见问题

**Q1：调性判错了怎么办？**
用 `--key` 覆盖。短旋律（4 小节）和结束在属音上的旋律容易判成关系小调，
`08_canon.mid` 就是典型：自动判成 b 小调，加 `--key "D major"` 才正确。

**Q2：伴奏太满 / 太空？**
先调 `--chords-per-bar`：`1` 更稳，`2` 更贴旋律但换和弦频繁；
再换织体：`pad` / `block` 更安静，`pop` / `arpeggio` 更流动。
实在不想要转调，加 `--no-modulate`。

**Q3：WAV 没生成？**
先加 `--no-wav` 确认 MIDI 正常；再确认 `tools\bin\fluidsynth\...\fluidsynth.exe`
和 `tools\bin\soundfonts\fluid-soundfont-3.1\FluidR3_GM.sf2` 还在。
不要输出到系统 Temp 目录，输出到本文件夹或桌面即可。

**Q4：`waltz` 听起来像柱式？**
`waltz` 只对 3/4 拍有效，4/4 会打印提示并自动退化为 `block`。

**Q5：多轨 MIDI 选错旋律？**
`.\run_cli.cmd 文件.mid --list-parts` 看每轨的音数与中位音高，
再用 `--track N` 指定。

**Q6：怎么确认代码没坏？**
运行 `.\run_tests.cmd`，最后显示 `ALL PASSED`；
同时会刷新 `output\route_a\report.md`。

**Q7：命令行中文乱码？**
用 `run_cli.cmd`（已设置 UTF-8）；直接 `python -m route_a.cli` 可能受终端编码影响。

**Q8：想批量跑？**
```powershell
Get-ChildItem *.mid | ForEach-Object {
    .\run_cli.cmd $_.FullName --style alberti
}
```

**Q9：拖进去报 `File is not in a correct format`？**
你拖的是输出文件 `_accomp_chords.txt`（和弦谱），不是旋律。改拖同名的 `.mid` 文件。
输入只接受 `.mid` / `.midi` / `.xml` / `.musicxml`；拖 `.txt` 现在会给出明确提示，不再抛异常。

**Q10：双击 `run_gui.cmd` 没反应？**
改用 `run_gui_debug.cmd`，控制台会显示报错；也可以在界面里直接点“浏览…”选文件。
界面生成时按钮会短暂变灰，等状态栏显示“生成完成”即可。

**Q11：混响在哪里？**
混响只作用于 **WAV**，MIDI 里没有。命令行加 `--reverb light|medium|hall`，
界面里在“混响”下拉框选“轻/中/大厅”。加混响后 WAV 末尾会多出 1–3 秒尾音，
不是文件损坏。

**Q12：用的是开源 DAW 的混响算法吗？**
开源 DAW 本身是宿主，混响在插件里：Freeverb（公有领域）、Zita-Rev1 / Calf / Dragonfly（GPL）。
直接挂 GPL 插件并随包分发，会让整个包受 GPL 约束，所以没有内置插件宿主。
本包提供 `--reverb-engine freeverb`：用公有领域的 Freeverb 算法离线生成脉冲响应再卷积，
零依赖、许可证干净。想要 Zita/Calf 的具体音色，把 `_accomp.mid` 拖进 Ardour/REAPER 挂插件即可。

**Q13：simple / ensemble / humanize 怎么选？**
- `--harmony simple`：圣咏、儿歌、合唱；去掉副属和 V7，只留 I/ii/IV/V/vi，避免《欢乐颂》里 E7 那种“油”感。
- `--ensemble strings|band`：只换 MIDI 音色组（弦乐 40/48/42，小乐队 4/4/33），不影响和声与织体。
- `--humanize light|strong`：按乐句加力度弧线，并给同时发声的音符整体 ±5–12ms 微时序；`off` 保持严格网格。

**Q14：为什么不用 DAW 的音源？**
DAW 的音源是 VST/VST3/SFZ 采样库，不是 DAW 自带：体积通常几 GB 到几十 GB，许可证多数不允许随包分发，
还需要插件宿主和安装/激活。本工具定位是**编曲生成器**，交付物是 MIDI；渲染交给 DAW 更合理。
如果只想换个好一点的音色：`--soundfont 你的.sf2`（支持 SF2/SF3）；
要完整的采样音源，就 `--no-wav` 导出 MIDI，拖进 DAW 挂 Kontakt/Spitfire 等。

**Q15：叠层选了钢琴却听不到？**
先确认**叠层1 选了织体**（只把“乐器1”设成 piano、叠层1 仍是“无”，不会生成叠层）。
如果叠层有音符但听不清，多半是掩蔽：钢琴在 43–55，弦乐在 48–84，同音区会盖住。
v3.4 已给钢琴/电钢/吉他/长笛加 +2–3dB 补偿（CC7 118 vs 弦乐 79）；
仍不够就把叠层抬高八度 `--layer-octave 12`，或先用 `--balance flat` 判断是不是音量问题。

## 10. 已知限制

- 调性识别在短旋律/关系大小调上仍会错（11 首里 1 首），请用 `--key`。
- 强拍冲突率是严格指标：经过音、九音都算冲突，1 和弦/小节时天然偏高。
- 没有人工听感验收，所有“好听”结论都来自指标与 MIDI 自检。
- 只支持单声部旋律；多声部会被压成最高音。
- 转调只在尾部乐句、属/下属方向、且条件严格时触发，不是任意转调。
