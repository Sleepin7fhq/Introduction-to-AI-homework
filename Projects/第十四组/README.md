# 把旋律变成乐队：可解释的自动配伴奏系统

一个面向“有旋律、但不会编曲”的创作者的自动配伴奏原型。输入一段单声部旋律（MIDI / MusicXML），几秒内输出可编辑的多轨伴奏 MIDI、试听 WAV、和弦谱，以及可选的分轨 WAV。

本项目不做端到端音频生成，而是把编曲拆成**分析、和声、编配、表现**四层可解释的决策：每一个和弦、每一条伴奏都能说明为什么出现，用户也可以逐项修改。最终音质交给 DAW，本工具负责把“动机”变成“可继续制作的多轨工程”。

> 课程作业项目。仓库只包含源码、测试、文档和小体积 IR；Python 运行时、音色库等大文件未上传，详见第 6 节。

---

## 1. 软件的作用

### 1.1 解决什么问题

从一句旋律到一首完整作品，中间隔着和声、织体、低音、配器、混音几道门槛。DAW 功能强大但学习曲线陡；自动伴奏软件风格模板化、参数黑箱；端到端 AI 生成音质惊艳，但输出不可编辑、不可解释、依赖云端或 GPU。

本项目选择“符号化编曲”路线：

- **输入**：单声部旋律，MIDI / MusicXML；
- **输出**：多轨 MIDI、WAV、和弦谱、分轨；
- **特点**：可解释、可修改、离线、CPU 可跑、单文件夹交付。

### 1.2 适合谁

- 有旋律但不会编曲的音乐爱好者；
- 需要给儿歌、校歌、短剧快速配伴奏的音乐教师；
- 需要 demo 的短视频创作者；
- 想理解和声、织体、配器逻辑的作曲初学者。

### 1.3 主要功能

- 调性、拍号、乐句、弱起分析；
- 候选和弦 + Viterbi 全局搜索，支持 V7、副属和弦、自动转调；
- 13 种伴奏织体；
- 低音转位与经过音；
- 副旋律、鼓轨；
- 1–2 层叠奏，支持音区、和弦音子集、节奏互补、旋律避让；
- 乐器档案：弦乐、钢琴、吉他、长笛、小号、贝斯、管风琴、人声等；
- CC7 声部平衡、CC11 表情自动化、力度曲线、微时序；
- 合成 IR / Freeverb / 真实厅堂 IR 三种混响；
- 图形界面、自动配置、分轨导出；
- 11 首示例、巴赫众赞歌、ASAP 真实钢琴谱基准。

## 2. 创作过程

项目最初的问题很朴素：**“写一个 AI，让它给一段已有旋律配伴奏，难度如何，需要多久？”**

评估后我们发现，端到端音频生成虽然 demo 效果好，但存在三个硬伤：输出不可编辑、决策不可解释、训练/推理资源不可控。于是选择路线 A：**music21 + 规则/动态规划 + FluidSynth**，先把“可解释的编曲决策”做扎实。

迭代大致分为七个阶段：

1. **环境与工具链验证**：确认 Python 3.12、music21、FluidSynth、SoundFont 在 Windows 上可离线运行；
2. **最小可用三轨**：旋律 + 和弦 + 低音，先跑通“输入 MIDI → 输出 WAV”；
3. **和声强化**：加入 V7、副属和弦、终止式、尾部自动转调，以及 `simple` 和声模式；
4. **织体与节奏**：扩展到 13 种织体，加入鼓轨、副旋律；
5. **可视化与空间**：tkinter 界面、钢琴卷帘、混响（合成 IR、Freeverb、真实 IR）；
6. **配器与表现**：多层叠奏、乐器档案、CC7 混音、CC11 表情、自动配置、分轨；
7. **基准驱动修正**：用巴赫众赞歌和 ASAP 真实钢琴谱做基准，反过来改调性判定、旋律提取、低音/和声骨架。

当前结果：

- 11 首示例：调性 11/11、终止 11/11、平均强拍冲突 28.6%、编曲总耗时约 4.8 秒；
- 巴赫众赞歌 20 首：调性 80%、终止 100%、和弦音 Jaccard 0.397；
- ASAP 20 首真实钢琴谱：0 崩溃、平均调性置信度 0.83、平均 7.5 秒/首；
- 34 项单元测试全部通过；
- 完整发布包约 500MB，复制即可运行。

## 3. 系统结构

```text
输入 → 分析 → 和声 → 编配 → 表现 → 输出
```

| 模块                          | 作用                          |
| --------------------------- | --------------------------- |
| `io.py`                     | 读取 MIDI/MusicXML、量化、选轨、旋律提取 |
| `analysis.py`               | 调性判定、乐句划分                   |
| `skeleton.py`               | 低音线、每拍和弦、根音直方图、终止和弦         |
| `harmony.py`                | 候选和弦、Viterbi、副属、转调          |
| `voicing.py`                | 声部排列、平行五八检查、低音选择            |
| `texture.py`                | 13 种织体生成                    |
| `bass.py`                   | 低音转位、经过音                    |
| `counter.py`                | 副旋律                         |
| `drums.py`                  | GM 鼓轨与鼓型                    |
| `instruments.py`            | 乐器音域、复音数、持续/拨奏、密度           |
| `variation.py`              | 乐句加花、伴奏避让旋律                 |
| `dynamics.py`               | 乐句力度曲线、微时序                  |
| `expression.py`             | CC11 表情自动化                  |
| `mixer.py`                  | CC7 声部平衡                    |
| `reverb.py` / `freeverb.py` | 卷积混响、Freeverb IR            |
| `render.py`                 | 写 MIDI、FluidSynth 渲染、分轨     |
| `auto.py`                   | 自动配置                        |
| `cli.py` / `gui.py`         | 命令行 / 图形界面                  |

## 4. 参数说明

### 4.1 输入输出

| 参数             | 默认                  | 作用                                           |
| -------------- | ------------------- | -------------------------------------------- |
| `input`        | 必填                  | 输入旋律 `.mid` / `.midi` / `.xml` / `.musicxml` |
| `-o, --output` | 输入名 + `_accomp.mid` | 输出 MIDI 路径                                   |
| `--wav`        | 同名 `.wav`           | 输出 WAV 路径                                    |
| `--no-wav`     | 关                   | 只出 MIDI，不渲染                                  |
| `--stems`      | 关                   | 额外导出每轨干声 WAV 到 `<名字>_stems/`                 |

输出还会生成 `<名字>_accomp_chords.txt` 和弦谱。

### 4.2 织体与结构

| 参数                 | 默认      | 作用            |
| ------------------ | ------- | ------------- |
| `--style`          | `block` | 主织体，13 选 1    |
| `--chords-per-bar` | `1`     | 每小节 1 或 2 个和弦 |
| `--phrase-bars`    | `4`     | 乐句长度（小节）      |
| `--no-modulate`    | 关       | 关闭尾部乐句自动转调    |

13 种织体：

| 织体         | 形态            | 适用       |
| ---------- | ------------- | -------- |
| `block`    | 柱式和弦，长音       | 圣咏、合唱、庄严 |
| `alberti`  | 低-高-中-高       | 古典、练习曲   |
| `arpeggio` | 分解和弦          | 抒情、流行    |
| `waltz`    | 低音+和弦，3/4     | 圆舞曲      |
| `pop`      | 低音每拍+反拍和弦     | 流行、轻快    |
| `pad`      | 长音持续          | 弦乐/合成器铺底 |
| `bossa`    | 低音 1、3 拍+切分和弦 | 波萨诺瓦     |
| `stride`   | 强拍低音+弱拍和弦     | 跨步钢琴     |
| `march`    | 低音-和弦交替       | 进行曲      |
| `guitar`   | 低音+八分指弹       | 民谣       |
| `arp16`    | 十六分宽琶音        | 电影感      |
| `sync`     | 3+3+2 切分      | 流行、R&B   |
| `scale`    | 八分音阶跑动        | 歌舞片、过门   |

### 4.3 和声、音色与调性

| 参数             | 默认         | 作用                                                 |
| -------------- | ---------- | -------------------------------------------------- |
| `--harmony`    | `rich`     | `rich` 保留副属/V7；`simple` 只留 I/ii/IV/V/vi            |
| `--ensemble`   | `piano`    | 音色组：`piano` / `strings` / `band`                   |
| `--soundfont`  | 包内 FluidR3 | `fluid` / `musescore` / `generaluser` 或 SF2/SF3 路径 |
| `--key`        | `auto`     | 指定调，如 `C`、`Am`、`G major`                           |
| `--track`      | 自动         | 多轨 MIDI 指定 part 序号                                 |
| `--list-parts` | —          | 只列出 part，帮助选轨                                      |

### 4.4 低音、副旋律与鼓

| 参数               | 默认     | 作用                                            |
| ---------------- | ------ | --------------------------------------------- |
| `--counter`      | 关      | 增加副旋律轨（通道 4）                                  |
| `--drums`        | 关      | 增加 GM 鼓轨（通道 10）                               |
| `--drum-pattern` | `auto` | `auto` / `pop` / `ballad` / `bossa` / `waltz` |

### 4.5 叠层与乐器

| 参数                      | 默认  | 作用                         |
| ----------------------- | --- | -------------------------- |
| `--layer STYLE[:INSTR]` | 无   | 叠加一层，可重复一次；如 `pad:strings` |
| `--layer-octave`        | `0` | 叠层八度：`-12` / `0` / `12`    |

可用乐器：`piano`、`epiano`、`strings`、`violin`、`cello`、`guitar`、`bass`、`flute`、`trumpet`、`organ`、`choir`、`synth`。

每层会自动做音区分工、只取 2 个和弦音、节奏互补、旋律避让，并按乐器档案决定音域、复音数与发声方式。

### 4.6 表现与混音

| 参数                | 默认           | 作用                                      |
| ----------------- | ------------ | --------------------------------------- |
| `--humanize`      | `off`        | 乐句力度曲线 + 微时序：`off` / `light` / `strong` |
| `--expression`    | `light`      | CC11 表情自动化：`off` / `light` / `strong`   |
| `--balance`       | `orchestral` | CC7 声部比例：`orchestral` / `pop` / `flat`  |
| `--reverb`        | `off`        | `off` / `light` / `medium` / `hall`     |
| `--reverb-engine` | `ir`         | `ir`（合成 IR）/ `freeverb`                 |
| `--ir`            | 无            | `hall` / `opera` / `church`，或 WAV 路径    |
| `--reverb-mix`    | 按档位          | 湿声比例 0–1                                |
| `--no-variation`  | 关            | 关闭乐句末尾加花                                |
| `--no-avoid`      | 关            | 关闭伴奏避让旋律                                |

### 4.7 自动配置

| 参数       | 作用                                |
| -------- | --------------------------------- |
| `--auto` | 分析旋律后自动选择织体、和声模式、音色组、叠层、混响、平衡、音源等 |

自动配置会覆盖手动参数，生成后仍可逐项修改。

### 4.8 图形界面

双击 `run_gui.cmd`（完整包）或 `run_gui_source.cmd`（源码）。左侧参数：

- 织体、和声节奏、乐句长度、调性；
- 和声模式、音色组、人性化、平衡；
- 副旋律、鼓轨、鼓型；
- 混响、算法、厅堂、音源；
- 叠层 1/2、乐器 1/2、叠层八度；
- 自动转调、乐句加花、表情、导出分轨；
- 输出目录、“自动配置”“生成伴奏”。

右侧显示钢琴卷帘、日志、播放/停止、打开 WAV/目录。

## 5. 运行方式

### 5.1 使用完整发布包（推荐演示）

完整包约 500MB，包含 Python 运行时、FluidSynth、三套音色库和真实 IR，**不在本仓库**。拿到发布包后：

```text
双击 run_gui.cmd
```

无需安装 Python、无需联网。

### 5.2 从源码运行

需要 Python 3.12、FluidSynth 2.x、一个 GM SoundFont：

```powershell
python -m pip install -r requirements.txt
```

把 FluidSynth 和 SoundFont 放到：

```text
tools/bin/fluidsynth/.../fluidsynth.exe
tools/bin/soundfonts/fluid-soundfont-3.1/FluidR3_GM.sf2
```

或用环境变量：

```powershell
$env:FLUIDSYNTH="D:\FluidSynth\bin\fluidsynth.exe"
$env:SOUNDFONT="D:\SoundFonts\FluidR3_GM.sf2"
```

命令行：

```powershell
python -m route_a.cli tests/data/02_ode_to_joy.mid --auto
```

图形界面：

```powershell
python -m route_a.gui
```

或双击 `run_cli_source.cmd` / `run_gui_source.cmd`。

### 5.3 测试与基准

```powershell
python tests/test_route_a.py
python tests/benchmark_chorales.py 20
python tests/benchmark_asap.py 20
```

ASAP 数据只用于本地评估（CC BY-NC-SA 4.0），未包含在仓库；缺少数据时脚本会跳过。

## 6. 未上传的文件及原因

GitHub 对单个文件有 100MB 硬限制，网页上传一次最多 100 个文件，仓库也不适合放几百 MB 的运行时。因此以下内容**没有上传**：

| 未上传内容                   | 大约体积             | 原因                             | 如何获取                                               |
| ----------------------- | ---------------- | ------------------------------ | -------------------------------------------------- |
| `runtime/`              | 约 277MB          | 自带 Python 运行时，文件多且大            | 使用完整发布包；或本机安装 Python 3.12                          |
| `tools/bin/soundfonts/` | 约 210MB（三套常用音色库） | FluidR3 142MB 超过单文件限制；三套音色库体积大 | 使用完整包；或从 FluidSynth / MuseScore / GeneralUser 官网下载 |
| `output/`               | 随生成变化            | 运行产物，不应进仓库                     | 运行后自动生成                                            |
| `tools/asap_dataset/`   | 数百 MB            | ASAP 为 CC BY-NC-SA 4.0，只用于本地评估 | 从 ASAP 官方仓库下载，放到 `tools/asap_dataset`              |

仓库里保留的是“可读、可改、可测”的部分：`route_a/` 源码、`tests/`、11 首示例 MIDI、文档、创意报告、PPT、三个小体积真实 IR。

## 7. 输出文件与 MIDI 通道

| 文件                   | 内容                                                                                 |
| -------------------- | ---------------------------------------------------------------------------------- |
| `_accomp.mid`        | 多轨 MIDI                                                                            |
| `_accomp.wav`        | 44.1kHz、双声道、峰值归一化 0.9                                                              |

| Counter   | 4   | 副旋律  |
| Layer 1/2 | 5/6 | 叠层   |
| Drums     | 10  | GM 鼓 |

## 8. 已知限制

- 规则系统能稳定产出“正确的伴奏”，但很难产出“有想法的编配”；
- 巴赫众赞歌调性 80%，真实曲目遇到局部转调/半终止会保守；
- 旋律提取可能跟丢内声部；
- 没有段落结构分析（AABA、主歌/副歌）；
- 音源是 GM SoundFont，演奏法和真实采样有差距；
- 没有音频输入，需要提供 MIDI/MusicXML；
- 界面按 1180×990 设计，720p 投影可能裁切，课堂演示建议 1080p 或自带笔记本。
