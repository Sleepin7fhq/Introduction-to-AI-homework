# 食量智配：校园食堂智能备餐模拟原型

这是课程创意作品的可复现演示，所有需求数据均为合成数据，不代表真实学校。无需账号、实时 API 或网络。

## 不安装 Python 直接演示
解压后双击 `demo.html`，使用浏览器打开。选择测试日期，先看预订量、预测和备餐建议，再点击显示实际需求。可修改手动备餐份数并评估损失。该页面是历史模拟回放，不会实时训练模型。

## 复现数据、模型、结果和演示页
推荐 Python 3.12/3.13，实际开发依赖版本列于 requirements.txt。
在代码目录打开终端：
```
python -m pip install -r requirements.txt
python model.py
```
模型会用固定随机种子 20261121 生成 synthetic_data.csv，重新训练3个随机森林，导出 outputs/test_predictions.csv、outputs/metrics.json 并生成 demo.html。训练112天、校准28天、测试28天，测试集不用于训练、调参或缓冲量估计。

## 文件
- model.py：模拟数据生成、预测、校准、备餐决策、指标计算及 HTML 导出
- demo_template.html：离线回放界面模板
- demo.html：生成的可直接打开的演示页
- synthetic_data.csv：168天 × 3类餐品共504条模拟记录
- outputs/test_predictions.csv：测试期84条记录及各方案预测、备餐量
- outputs/metrics.json：汇总及分餐品结果、缓冲系数

## 指标与边界
基准为训练期同餐品同星期均值；AI为随机森林。两种预测均以各自独立校准期残差的71.43%分位数加缓冲，再向上取整。剩余损失权重1、缺餐损失权重2.5，非真实人民币。测试期结果：基准/AI WAPE 12.81%/7.20%；剩余985/611份；缺餐348/155份；需求满足率96.27%/98.34%；模拟损失1855/998.5。真实部署需要实际需求记录、食品安全流程、人工确认及独立验证。
