# 随手拍·随手问 — 视障者生活信息助手

面向视障人士的任务型视觉问答小程序：拍一张照片并说出想知道的事，系统**先判断照片能不能用**，不能用就告诉用户怎么调整（靠近、拿稳、翻面），能用才给出可直接执行的语音回答。

## 与普通 OCR 朗读工具的区别

| | 普通 OCR 朗读 | 本作品 |
|---|---|---|
| 输出 | 把整页文字念一遍 | 只回答你要的那件事 |
| 拍糊了 | 报错或念出乱码 | 用一句话告诉你怎么重拍 |
| 缺反面 | 不知道 | 提示"请翻到有用法用量的一面" |
| 药品 | 全文朗读，用户自行找剂量 | 直接给"一次几片、一日几次"+ 原文依据 + 请与药师确认 |

## 目录结构

```
miniprogram/            小程序前端
  pages/index/          拍摄页（全屏可触达 + 自朗读按钮）
  utils/tts.js          语音播报适配层（同声传译插件，失败降级为音效+震动）
  assets/*.wav          触达音效（点按 / 成功 / 需重拍）
cloudfunctions/vqa/     云函数：质量判断 + 任务型问答（调用 GLM-5.3-Flash）
cloudfunctions/speech/  云函数：语音识别(ASR) + 语音合成(TTS)，腾讯云一句话识别/基础合成
  templates.js          场景模板与系统提示词
```

## 运行步骤

1. 微信公众平台注册小程序（个人主体即可），获取 **AppID**
2. 把 `project.config.json` 里的 `REPLACE_WITH_YOUR_APPID` 替换为你的 AppID
3. 小程序后台 → 开发 → 云开发 → 开通环境
4. 开发者工具导入本目录 → 右键 `cloudfunctions/vqa` → 上传并部署（云端安装依赖）
5. 云开发控制台 → 云函数 `vqa` → 配置 → 环境变量：
   - `GLM_API_KEY`：智谱开放平台（bigmodel.cn）API Key
   - `GLM_MODEL`：可选，默认 `glm-5.3-flash`
6. 小程序后台 → 设置 → 服务内容声明 → **用户隐私保护指引**，勾选「摄像头」「麦克风」「相册」，否则相机无法调用
7. 小程序后台 → 第三方设置 → 插件管理，添加「**同声传译**」插件（provider `wx069ba97219f66d99`），版本以控制台显示为准
8. 开发者工具点「预览」，手机微信扫码即可真机运行

## 合规与安全

- 不采集手机号、昵称、头像、位置，只上传用户主动拍摄的照片与主动说出的语音
- 模型密钥只存在云函数环境变量，绝不下发到前端
- 药品场景仅复述图中原文，明确提示"请与药师或医生确认"，不做剂量推断与治疗建议
- 模型输出解析失败时**一律判定为需要重拍**，不返回可能编造的内容
