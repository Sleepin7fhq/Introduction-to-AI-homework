# 饭点雷达 CanteenAI

面向东南大学四牌楼校区学生的智能个人用餐决策 Web 应用，用于《人工智能导论》课程创意项目展示。

> 重要说明：项目内的菜品、价格、食堂位置、排队时间和拥挤预测均为模拟数据，仅用于课堂演示，不代表学校食堂的真实营业信息或实时状态。

## Windows 打开方式

### 最简单：直接双击

1. 打开项目文件夹 `CanteenAI`。
2. 双击 `index.html`。
3. 系统会使用默认浏览器打开应用。

推荐使用最新版 Microsoft Edge 或 Chrome。所有功能都能在本地运行，不需要联网。

### 更稳定的本地服务器方式（可选）

如果电脑装有 Python，在项目文件夹地址栏输入 `cmd` 并回车，然后运行：

```bat
python -m http.server 8000
```

浏览器打开 `http://localhost:8000`。退出时在命令窗口按 `Ctrl+C`。

## 三分钟课堂演示建议

1. 在智能推荐中选择“赶课 · 30分钟速战速决”，展示可解释推荐。
2. 在决策区切换到“选择困难”，点击“载入演示案例”，展示雷达图和落选原因。
3. 切换到“盲盒探索”，选择“适度冒险”并开盒，强调它不是随机抽签，忌口仍是硬约束。
4. 切换到“多人组队”，载入四人案例，展示同一食堂的个人配菜、公平指数和冲突分析。
5. 切换当前位置并拖动“食堂拥挤雷达”的时间滑块，观察距离、排队和推荐同步变化。

## 四大用餐模式

### 智能推荐

原有个人推荐完整保留。根据预算、位置、空闲时间、口味和忌口，计算六因素匹配度并解释原因；支持自然语言输入与四个一键场景。

### 选择困难

- 输入 2—3 个纠结菜品，可从数据库选择，也可手动填写数据库外菜品的价格、口味和食堂。
- 按价格、口味、排队、距离和历史偏好评分。
- 用 Canvas 雷达图展示差异，并解释其他候选未胜出的主要原因。
- 点击“载入演示案例”可快速展示三菜对比。

### 盲盒探索

- 提供稳妥尝鲜、适度冒险、大胆探索三个等级。
- 结合历史偏好相似度、未吃过的新颖度、反馈和时间实用性排序，不使用简单随机数。
- 任何等级都会先执行忌口与过敏过滤。
- 支持喜欢、不喜欢、吃过了和再开一个反馈，结果会写入现有饮食记忆模型。

### 多人组队

- 支持 2—6 人分别填写昵称、预算、口味、忌口和可用时间。
- 先寻找共同可行食堂，再为每位成员分别选菜，不要求吃同一道菜。
- 同时优化平均满意度与最低个人满意度，显示个人满意度条和冲突分析。
- 如果所有食堂都无法满足硬约束，会明确显示无可行方案。

## 功能清单

- 60 条明确标注的模拟菜品记录（20 类模拟菜品 × 3 个食堂）
- 仅保留沙塘园食堂、莘园食堂、香园食堂三个食堂
- 7 个校内位置：礼东、礼西、大礼堂、图书馆、五四楼、东南院、中山院
- 参考 `campus-map.jpg` 相对方位重绘的简化校园示意图
- 四种可自由切换的用餐决策模式
- 五维菜品对比雷达图与数据库外菜品手动补充
- 三等级非随机探索盲盒与反馈学习
- 2—6 人公平组队推荐和偏好冲突分析
- 预算、位置、时间、口味、忌口个性化输入
- 六因素加权推荐和推荐原因解释
- 校园示意地图、拥挤热度、Canvas 趋势曲线
- 时间滑块驱动的排队与推荐动态模拟
- 本地正则表达式和关键词自然语言解析
- `localStorage` 饮食历史、收藏与偏好反馈
- 总耗时（步行 + 排队 + 用餐）对比
- 四种预设演示场景与一键演示
- 手机、平板和电脑响应式布局

## 文件说明

- `index.html`：页面结构
- `styles.css`：视觉设计与响应式布局
- `app.js`：数据、算法、图表和交互逻辑
- `算法原理说明.md`：模型与公式说明
- `测试记录.md`：测试范围、方法和结果

## 隐私与数据

应用不上传任何信息。饮食历史、收藏和反馈只保存在当前浏览器的 `localStorage` 中。点击页面中的“清空饮食记忆”即可删除。

## 地图与时间口径

项目中的简化地图参考了项目文件夹内的 `campus-map.jpg`。地图只表达建筑与食堂的大致相对关系，不是导航地图。步行时间是用于算法演示的合理模拟估算，排队时间由本地曲线模型生成，不是实时校园数据。
