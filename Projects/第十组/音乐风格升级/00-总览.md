# 音乐风格升级 · 总览

**版本**：2.1.0　**日期**：2026-11-21

这次升级只解决三件事：**音色太差、风格太假、热梗库太小**。没有推倒重做，所有改动都在原有架构内：

| 模块 | 改了什么 | 是否影响既有功能 |
|---|---|---|
| 音色引擎 | 重写 `src/music/voices.ts`：分层鼓组、双层贝斯、detune 主音、共振峰人声切片、效果发送 | 播放接口不变，原有 7 个流派照常工作 |
| 风格库 | 新增 `src/music/styles.ts`：7 个完整风格预设（含音色画像） | 旧流派保留，新旧共存 |
| 生成器 | 风格化鼓组 preset、人声切片轨、**修复风格覆盖不生效的 bug** | 修复而非破坏：锁定风格现在真的生效 |
| 热梗库 | 新增 `src/producer/memeKB.ts`：42 条带来源与置信度 | 两级检索：手工 16 条优先，知识库兜底 |
| 离线渲染 | 新增 `src/music/render.ts` + 下载钩子 | 新增能力，不改实时播放 |

## 三句话结论

1. **原来的音色是"一个振荡器 + 一条包络"**，没有分层、没有失真、没有效果发送——所以像提示音。现在鼓组三层、贝斯双层、主音 3–5 层 detune + 滤波 + 延迟，并加了总线 EQ 与驱动。
2. **风格预设以前只是标签**。这次实测发现 style 覆盖根本没传进生成器（`composeSongEx` 又重新按文本推断了一遍），已修复：锁定风格现在同时决定 BPM、调式、鼓组、贝斯、主音、切片。
3. **热梗库从 16 条扩到 58 条**（16 手工 + 42 研究），每条研究条目都带 `sources / confidence / verified`，未核实的明确标「待核实」，界面会显示置信度徽章。
