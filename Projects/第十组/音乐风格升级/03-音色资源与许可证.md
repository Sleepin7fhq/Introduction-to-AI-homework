# 音色资源与许可证

## 结论：本次升级**没有引入任何采样素材**

所有声音都是运行时用 Tone.js 的振荡器/噪声源**程序化合成**的。没有任何 mp3/wav 采样被塞进项目，
也没有从 B 站或任何平台下载音频。

| 资源 | 用途 | 许可证 | 是否随项目分发 |
|---|---|---|---|
| **Tone.js 15.1** | Web Audio 合成与调度 | MIT | 是（node_modules 依赖） |
| **Web Audio API** | 浏览器音频引擎 | W3C 标准 | 否（浏览器内置） |
| **ACE-Step 1.5 权重** | 神经网络音频 | 按其官方仓库许可证 | **否**（只在本地 `.tmp/ace/models` 使用，不随作品分发） |
| **ffmpeg（静态构建）** | 仅用于把录屏编码成 MP4（构建期工具） | 该构建为 GPL 系列（含 libx264） | **否**（只在 `.render/ffmpeg.exe`，不进入交付物） |
| **微软雅黑 / Consolas** | PPT、文档字体 | 随 Windows 授权使用 | 否（不嵌入文件） |
| **python-pptx / python-docx / Pillow / numpy** | 生成展示材料 | MIT / BSD / MIT / BSD | 否（构建期） |

## 人声切片怎么解决"版权"问题

司凤风格的核心是"怪叫人声"。直接采样原曲会侵权，所以本项目用**共振峰合成**：

```
锯齿波 → 3 个并联带通（元音共振峰：a=730/1090/2440Hz）
      → 颤音 5.6Hz → 轻失真 → 延迟/混响送出
```

得到的是"啊/哦/诶"这类元音色彩的短切片——**有人的元音特征，但不是任何人的声音**，
可以自由使用。它不完美（见 05 的遗留问题），但方向上解决了"不能采样又要有人声感"的矛盾。

## 热梗内容的使用边界

- 只引用**梗的名称、语境、网络用法**这类事实性信息，并标注来源链接；
- 不搬运原视频、原音频、原字幕文件；
- 生成的音乐是"受梗启发的新编曲"，不是原曲的翻录或 remix 采样；
- 研究文档中对来源的引用仅用于说明，不构成再分发。

## 如果将来要引入采样

建议按这个顺序选：

1. **CC0**：freesound.org 的 CC0 包、Splice 免费包（需确认条款）；
2. **CC-BY**：需在作品内署名（可直接写进 PPT 附录）；
3. **自制录制**：自己录的拍手/人声哼唱，用 Audacity 切成 one-shot；
4. ❌ 不要用：B 站视频音轨、商业歌曲片段、来源不明的"采样包"。

引入后需要：转成 48kHz/16bit、统一响度（-14 LUFS 左右）、在 `03-音色资源与许可证.md` 登记来源与许可证。
