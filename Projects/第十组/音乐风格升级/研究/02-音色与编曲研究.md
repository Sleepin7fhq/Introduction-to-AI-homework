# 02 · 电子音乐音色与编曲研究（重点：声音不"薄"、不像提示音）

- 研究时间：2026-11-21
- 研究员：sound-research（DSH Studio 2.0 音乐风格研究员）
- 目标：给出**参数级**结论（Hz / ms / dB / 音分 / 层数），可直接写进合成器与效果链配置
- 标记约定：**【事实】**=来源明确写到；**【推断】**=由来源外推；**【经验值】**=行业常用区间，本次文献未直接给出

## 0. 一页速查（先给结论）

| 元素 | 关键数值 | 一句话做法 |
|---|---|---|
| Kick | 基频 50–60 Hz（G1–B1 附近）；pitch envelope 深度 8× 起；sweep 时长 30–60 ms（techno 可到 80–150 ms） | sub（40–80 Hz 正弦）+ body（100–250 Hz）+ click（2–5 kHz，前 20 ms）三层叠加 |
| Bass | sub 40–80 Hz 单声道；mid 150–500 Hz 加失真 | 120–200 Hz 分频，失真只加在 mid 层 |
| Lead | 7–9 声部 unison，3 个 saw，detune ±15–30 音分 | HP 200–300 Hz + 延迟 1/8 附点 + 混响 send −12 dB |
| Snare/Clap | body 150–300 Hz / crack 2–5 kHz / air 6–14 kHz | Clap 带通中心 1 kHz，HP 1 kHz、LP 6 kHz |
| Hi-hat | 高通 6–8 kHz（闭），sizzle 层 8–10 kHz | 闭镲衰减 30–60 ms，开镲 150–250 ms |
| Drop | 前 1 拍～1 小节抽空，能量差 ≥ 6 dB | 白噪 riser 4–8 小节，LP 200 Hz→8 kHz |
| 不"薄" | 四个频段都要有能量：40–80 / 150–300 / 2–5k / 8–12k | 每层至少覆盖 3 个八度，低频单声道，并行失真 30% |

## 1. Kick：三层结构 + 两级失真

### 1.1 三层分工（【经验值/推断】，与来源的 Hardstyle 流程一致）

| 层 | 频段 | 波形/素材 | 包络 | 电平 |
|---|---|---|---|---|
| Sub | 40–80 Hz | 正弦，跟调性（G1–B1） | attack 0–2 ms，decay 80–200 ms | 0 dB（基准） |
| Body | 100–250 Hz | 正弦/三角，或 909 kick 本体 | decay 40–120 ms | −3～−6 dB |
| Click | 2–5 kHz | 高通后的 909 头部，只留前 20 ms | decay 5–20 ms | −6～−12 dB |

- **【事实】** 硬派 techno kick 的做法：选 100–250 Hz 有短 body 的样本；高通 60–80 Hz；400–600 Hz 若"箱声"则切 2–4 dB；body 在 1 kHz 附近温和低通；click 用另一个 kick 的头部（909 高通 2 kHz，只留前 20 ms）。（来源：Myloops 文章，仅读搜索摘要）
- **【事实】** 底鼓基频从 50–60 Hz（G1–B1）起调较稳；attack/sustain/release 先归零，用 decay 控制 pitch sweep 长度、用 envelope amount 控制深度。（Elektronauts 论坛）

### 1.2 Pitch envelope（"有冲击"的核心）

| 参数 | 值 | 说明 |
|---|---|---|
| 起始频率 | 150–200 Hz | 太低听不出"踢"，太高像鼓皮 |
| 终止频率 | 50–60 Hz | 与调性对齐（G1=49 Hz、A1=55 Hz） |
| sweep 时长 | 30–60 ms（clicky）/ 80–150 ms（techno/rave 长尾） | 越长越"techno"，越短越"clicky" |
| 深度 | 8× 起（约 +36 半音） | KVR 论坛经验：depth 8× 或更高 |
| 曲线 | 指数衰减 | 线性会"呜" |
| 音高跟随 | 全曲固定根音（如 G1） | 不要每小节变调，低频会乱 |

### 1.3 Hardstyle 级失真链（逐级数值，可直接照抄）

来源：Midifan 编译 Native Instruments 官方教程《如何制作 Hardstyle 音乐？》（2024-04，原文 Tim Cant）。**这是本轮唯一给出"逐级 EQ/失真/重采样"完整数值的来源，可信度较高。**

| 步骤 | 处理 | 参数 |
|---|---|---|
| 0 | 工程速度 | 160 BPM |
| 1 | 素材 | 909 kick（Kick 909X 2），每拍 C3，力度 100 |
| 2 | 失真 1 | Dirt "Devil Fish"，Drive A = 68.5 |
| 3 | 失真前 EQ | −13.3 dB @ 50.5 Hz；−11.5 dB @ 170 Hz；+11.8 dB @ 383 Hz |
| 4 | 失真 2 | Bite "Squeek"：Drive A 9.5、Amount A 100、Drive B 32.5 |
| 5 | 失真前 EQ 2 | +4.59 dB @ 49.5 Hz；+5.83 dB @ 979 Hz（Q 0.22）；+10.5 dB @ 1.86 kHz |
| 6 | 重采样 | 拖进采样器；ADSR：Sustain −14 dB、Decay 76.1 ms、Release 173 ms |
| 7 | 再次失真 | Bite bitcrusher "Low Res"：Rate 9.86 kHz、Bits 6、Crunch 51、Saturation 8 dB、Mix 66.5% |
| 8 | 失真前 EQ 3 | +4.09 dB @ 1.11 kHz（Q 0.13） |
| 9 | 瞬态整形 | 分频点 200 Hz / 6 kHz；mid Sustain −6.2；high Sustain +12.8 |
| 10 | 最终 EQ | +1.43 dB @ 47.4 Hz；+2.14 dB @ 250 Hz；−8.06 dB @ 861 Hz |
| 11 | 叠层 | 辅助 kick（909 26）电平 −15.8 dB，主体 −1.2 dB，辅助轨上移 +1 半音到 C#3 |
| 12 | 侧链 | 主体 kick 由辅助 kick 触发压缩，Threshold −24 dB |
| 13 | 节奏 | 4 小节；每拍 1 个 kick（力度 120）；第 2 小节最后一拍三连音八分；第 4 小节最后一拍改两个八分 |

> 这些数值是"某个特定音色"的配方，**不能无脑套到所有 BPM**：160 BPM 下 76 ms decay 刚好不糊；128 BPM 下同样 decay 会显得短，建议 100–130 ms。

### 1.4 让 kick "不像提示音"的检查项

1. **必须有噪声成分**：click 层加 5%–10% 白噪（1–5 ms），纯正弦听起来像"滴"。
2. **必须有谐波**：sub 层加 2–3 次谐波（饱和 2 dB），否则小喇叭上听不见。
3. **必须有音高下滑**：没有 pitch envelope 的正弦 = 提示音。
4. **attack 微变化**：每个 kick 的 click 电平随机 ±1 dB，避免"电子表"感。
5. **长度**：40 ms 以下是"点"，80–150 ms 是"鼓"，300 ms 以上是"808"。

## 2. Bass：sub 与 mid 分层

### 2.1 分频与处理

| 层 | 频段 | 波形 | 处理 | 声像 |
|---|---|---|---|---|
| Sub | 40–80 Hz | 正弦 | 单声道；侧链 kick（−3～−6 dB） | 中置 |
| Mid | 150–500 Hz | 锯齿/方波，2–3 个 detune | 失真（drive 6–12 dB）→ 低通 500–800 Hz | 轻微加宽 |
| Top/谐波 | 800 Hz–2 kHz | 从 mid 层失真产生 | 高通 800 Hz，电平 −12 dB | 宽 |

- **【事实】** NI Hardstyle 教程的通用处理顺序是"失真 → 滤波 → gate → 侧链压缩"：其锯齿波声部（April Dawn）先高通 235 Hz，再上失真（Dirt "Acid"），再 gate（Bite "Gate 9"），最后侧链压缩 Threshold −38.9 dB。这组数值原本是给 lead 用的（见 3.2），**bass 可沿用同样的顺序，但高通要降到 30–80 Hz**——即**中高频靠失真+滤波塑造，低频靠侧链让位**。
- **【经验值】** 分频点 120–200 Hz；分频用线性相位或 24 dB/oct，避免相位打架。
- **【推断】** "薄"的常见原因：sub 与 mid 分频点处凹陷（两者都衰减），或 mid 层低通切得太低（< 400 Hz），导致 300–800 Hz 空洞。

### 2.2 低通包络（pluck bass）

| 参数 | 值 |
|---|---|
| 起始 cutoff | 1.5–3 kHz |
| 终止 cutoff | 150–300 Hz |
| 衰减时间 | 80–200 ms |
| 共振 | Q 2–5（会"哇"一声） |
| 包络量 | 60%–100% |

### 2.3 Techno rumble（滚动低频）

- **【事实/摘要】** Ableton 做法：取 909 kick → 拉长成 sub bass（要"Boom"）→ 建 Audio Effect Rack 多链 → 加 Saturator 增厚 → EQ Eight 收尾 → 用 gate/侧链控制成 1/16 或 1/8 的滚动。
- **可执行配方【推断+经验值】**：
  1. Kick 采样 → 混响 100% wet，decay 1.0–2.0 s，pre-delay 0 ms，HP 30 Hz / LP 200 Hz（混响前）。
  2. 混响后 → gate，阈值调到只留 1/16～1/8 的尾巴（约 90–180 ms @ 128 BPM）。
  3. → 饱和（drive 6–10 dB）→ EQ：HP 30 Hz、LP 180–250 Hz、300–500 Hz 切 2–3 dB。
  4. → 侧链 kick，−4～−6 dB，attack 5–10 ms、release 80–150 ms。
  5. 结果：kick 后面拖着一条"引擎轰鸣"，是 techno 不薄的秘密。

## 3. Lead：Supersaw 的数量与 detune

### 3.1 声部配置

| 参数 | 推荐 | 依据 |
|---|---|---|
| 振荡器数 | 3 个 saw | Syntorial 的 trance lead 教程 |
| 每 osc unison 声部 | 9 voice | 同上（原文 "9 voice unison"） |
| unison detune | 调到"刚开始听起来有点走音" | 同上；量化约 ±15–30 音分 |
| osc 间微调 | Osc2 fine 往下、Osc3 往上 | 同上 |
| 立体声 detune | ±20～±50 音分 | Roland FANTOM 参数表：Stereo Detune −50～+50 cent |
| 总声部数上限 | 27（3×9） | 超过 CPU 吃紧且相位糊 |

- **【事实】** Supersaw 学术论文（松本和樹，早稻田）专门研究"unison 声部数"与"detune 量"两个参数——说明这两个是 supersaw 音色的决定性变量。
- **【经验值】** 想让 lead "厚"：7–9 声部 + 每个声部 ±0.3–0.6 ms 的起音随机（避免相位完全同相导致"薄"）。

### 3.2 滤波与空间

| 处理 | 参数 | 说明 |
|---|---|---|
| 高通 | 200–300 Hz（NI 教程用 235 Hz） | 去低频泥 |
| 低通 | 24 dB/oct，cutoff 自动化 280 Hz → 16.6 kHz（跨 8 小节） | NI 教程原值：280 Hz→16.6 kHz |
| 延迟 | 1/8 附点（dotted 8th），ping-pong，feedback 25%–35%，wet 15%–25% | 宽而不糊 |
| 混响 | plate/hall，decay 1.2–2.0 s，send −12 dB（即 wet 约 12%） | 别用长混响做主空间 |
| 侧链 | 由 kick 触发，Threshold −38.9 dB（NI 教程值） | 抽吸感 |
| 失真 | 并行失真 20%–30%，或 bitcrush gate（"Gate 9"） | NI 教程用 Dirt "Acid" + Bite gate |
| 宽度 | M/S：mid 保留，side +2～4 dB（> 300 Hz） | 低频保持单声道 |

### 3.3 Screech（Hardstyle 尖啸）

- **【事实】** 用 Massive X 的 "Scream Snare" 预置做底 → 复制 kick 的 MIDI 并上移到 A4 → 上失真（Dirt "Acid"）→ 音量 −10.9 dB。（NI 教程）
- **【推断】** 本质是"用锯齿/共振峰把 kick 的节奏变成旋律性噪声"，所以它天然和 kick 锁在一起。

## 4. Snare / Clap / Hi-hat

### 4.1 三层频段（【事实】，Sound Architect 摘要）

| 层 | 频段 | 作用 |
|---|---|---|
| Body | 150–300 Hz | 重量 |
| Crack/Attack | 2–5 kHz | 冲击、存在感 |
| Air/Noise | 6–14 kHz | 空气、宽度 |

- **【事实】** Clap 主频约 1 kHz，支撑频率从 200 Hz 到 12 kHz（Aria Music 摘要）。
- **【事实】** Snare 主体 150 Hz 左右，清晰度 2.5–3.5 kHz（同上）。
- **【事实】** Clap 处理：高通 1 kHz、低通 6 kHz；或者用 1–6 kHz 带通白噪做"响弦"、4 kHz 以上高通噪声爆发做"咔"（SampleLoom / Sound Architect 摘要）。

### 4.2 Clap 配方（结合 NI 教程的具体数值）

| 步骤 | 参数 |
|---|---|
| 音源 | clap 采样或 Massive X "Clap Master" |
| EQ | +15 dB @ 267 Hz、+15 dB @ 696 Hz（NI 教程原值，目的：补 body） |
| 高通 | 495 Hz |
| 失真 | Dirt：Drive A 97.5、Drive B 27 |
| 侧链 | Threshold −15.7 dB |
| 尾音 | 三连音滚奏（最后一拍力度 127） |
| 混响 | 0.4–0.8 s，wet 10%–15% |

> 注意：NI 那组 +15 dB 的 EQ 是在"重失真之前"做的，属于特例；常规做 clap 别直接 +15 dB @ 267 Hz，会轰。**代码里应作为"preset 宏"，而不是默认 EQ。**

### 4.3 Snare

| 步骤 | 参数 |
|---|---|
| 音源 | 909/808 snare 或噪声层 |
| EQ | +6.07 dB @ 1.21 kHz（NI 教程值） |
| 高通 | 255 Hz |
| 混响 | "Caramel Guitar" 类短混响，wet 10% |
| 侧链 | Threshold −15.7 dB |
| 衰减 | 80–250 ms |

### 4.4 Hi-hat

| 参数 | 闭镲 | 开镲 |
|---|---|---|
| 高通 | 6–8 kHz（12 dB/oct） | 5–7 kHz |
| 衰减 | 30–60 ms | 150–400 ms |
| 亮度提升 | 8–12 kHz +2～3 dB | 同 |
| 去泥 | 200 Hz 以下高通 | 同 |
| 叠加 | 加一层 8–10 kHz 高通的"嘶"声（sizzle） | 同 |
| 声像 | 轻微左右交替 ±15% | 中置或宽 |

- **【事实】** Hi-hat EQ 指南：200 Hz 以下高通去隆隆；8–12 kHz 找清晰度与亮度（SoundOracle 摘要）。
- **【事实】** Ableton 论坛做法：hi-hat 叠一层 8–10 kHz 高通的电子"嘶"声，让 sustain 段有空气感（可再加 bit reduction）。

## 5. 段落能量：Drop 前怎么"抽空"

### 5.1 "抽空"的四种手法（可叠加）

| 手法 | 时长 | 参数 | 效果 |
|---|---|---|---|
| 全静音 gap | 1/8～1/4 拍（45–90 ms @ 167 BPM） | 所有轨 −∞ | 最狠，适合 rave/鬼畜 |
| 低切 sweep | 1–2 小节 | 全曲 HP 从 20 Hz 扫到 800 Hz | "水下感" |
| 撤 kick + sub | 1–2 拍 | 只留人声/hat | 呼吸感 |
| 反向混响 | 1 拍 | 人声 reverse + 混响 100% wet | 吸入 Drop |

### 5.2 Riser（白噪上升）

- **【事实/摘要】** 做法：白噪 → 滤波器 cutoff 自动化向上扫（build 段），同时音量、混响、宽度一起上升；可用合成器噪声振荡器或长噪声文件。（Plugg Supply、Gearspace 摘要）
- **参数【推断+经验值】**：
  - 长度：4–8 小节（167 BPM 下 5.7–11.5 s）。
  - 滤波：LP 200 Hz → 8 kHz（24 dB/oct），共振 Q 2–4。
  - 音量：−∞ → −6 dB（线性或指数）。
  - 混响：send 0% → 30%，decay 2 s。
  - 宽度：mono → 100%。
  - 最后 1/8 拍骤停。

### 5.3 Impact / Downlifter

| 元素 | 参数 |
|---|---|
| Impact | 808 sub（40–60 Hz，decay 1–2 s）+ 反向 crash + 短噪声爆发；峰值 −3 dBFS，占 Drop 首拍 |
| Downlifter | 反向 riser（8 kHz → 200 Hz），长度 2–4 小节，接在 Drop 之后 |
| Crash | 高通 300 Hz，decay 1.5–2.5 s，宽声场 |

### 5.4 能量差的量化标准

| 指标 | 建议值 | 测法 |
|---|---|---|
| Drop 前后短时 RMS 差 | ≥ 6 dB（8–10 dB 更"炸"） | 100 ms 窗 |
| Drop 首拍峰值 | −3～−1 dBFS | 真峰值 |
| Drop 低频能量（40–80 Hz） | 比 Verse 高 4–6 dB | 频谱 |
| 整体 LUFS（rave/鬼畜） | −8～−10 LUFS | 集成响度 |
| 真峰值 | ≤ −0.8 dBTP | 限制器 |

## 6. 为什么"薄"、为什么像"提示音"：诊断表

### 6.1 "薄"的 7 个原因与修法

| # | 原因 | 检测 | 修法 |
|---|---|---|---|
| 1 | 只有中高频，没有 sub | 40–80 Hz 能量 < −40 dBFS | 加 sub 层或 808 |
| 2 | sub 与 mid 分频处凹陷 | 120–200 Hz 有 notch | 改分频点或加 3 dB 补丁 |
| 3 | 所有元素都单声道 | 宽度 < 10% | > 300 Hz 加宽（Haas 10–20 ms 或 M/S） |
| 4 | 没有失真/谐波 | 2–5 kHz 能量低 | 并行失真 30%、饱和 2–3 dB |
| 5 | 起音太整齐 | 所有 attack 完全同相 | 每层起音随机 0.3–0.6 ms |
| 6 | 混响太长 | RT60 > 2.5 s 且 wet > 25% | 缩短到 1.2–2 s、wet 10%–15% |
| 7 | 母带过度限制 | crest factor < 6 dB | 限制器少压 2 dB，LUFS 目标降 1–2 |

### 6.2 "像提示音"的 6 个特征（命中 2 条以上就要改）

1. 纯正弦、无谐波、无噪声。
2. 恒定音高、无 pitch envelope、无 vibrato。
3. attack < 2 ms 且 decay < 50 ms（"滴"）。
4. 8-bit 以下方波 + 无滤波。
5. 完全量化、无 humanize（时值误差 0 ms）。
6. 单声道 + 无混响 + 无延迟。

### 6.3 去"提示音"的默认处理链

```
source → 高通 100 Hz → 饱和 (drive 6 dB) → 低通 8 kHz (24 dB/oct)
→ 并行失真 30% → 短混响 0.4 s / wet 12% → 延迟 1/8 (wet 10%)
→ 立体声加宽 (>300 Hz) → 限制器 −1 dB
```

- **【经验值】** 加 5%–10% 噪声层、vibrato 5–6 Hz / 深度 10–20 音分、每个音起音随机 ±5–15 ms，是"去电子表感"最便宜的三招。

### 6.4 全频段覆盖检查（"不薄"的量化标准）

| 频段 | 目标 | 检查方法 |
|---|---|---|
| 40–80 Hz | 有能量，单声道 | 频谱；mid/side 看 side 应 < −20 dB |
| 150–300 Hz | 有 body，但不浑 | 频谱；300–500 Hz 可 −2 dB |
| 2–5 kHz | 有存在感 | 频谱；人声/lead 主战场 |
| 8–12 kHz | 有空气 | 频谱；hat/air 层 |
| 整体 | 每层至少覆盖 3 个八度 | 单独 solo 每层听 |

## 8. 对 DSH Studio 的具体改造建议

### 8.1 新增音色预设（参数直接可用）

#### `kick_rave`（通用 rave/鬼畜四踩）

| 参数 | 值 |
|---|---|
| sub 频率 | 50 Hz（跟调性，G1） |
| pitch env | 200 Hz → 50 Hz，40 ms，指数 |
| sub decay | 120 ms |
| body | 180 Hz，decay 60 ms，−4 dB |
| click | 909 头，HP 2 kHz，前 20 ms，−8 dB |
| 噪声层 | 8% 白噪，5 ms |
| 失真 | 并行 40%，drive 8 dB |
| 输出 | −6 dBFS，单声道 |

#### `kick_hardstyle`（150–160 BPM）

- 直接采用 1.3 表的 13 步；默认 155 BPM，decay 76 ms；侧链 threshold −24 dB。

#### `supersaw_lead`

| 参数 | 值 |
|---|---|
| osc | 3 × saw，各 9 voice unison |
| detune | ±20 音分（stereo detune ±30 音分） |
| HP | 235 Hz |
| LP | 24 dB/oct，cutoff 自动化 280 Hz→16.6 kHz / 8 小节 |
| 延迟 | 1/8 附点，feedback 30%，wet 20% |
| 混响 | 1.6 s，send −12 dB |
| 侧链 | threshold −39 dB |
| 宽度 | side +3 dB（> 300 Hz） |

#### `clap_rave`

| 参数 | 值 |
|---|---|
| 带通中心 | 1 kHz（Q 1.5）+ 6–12 kHz 噪声层 |
| 高通 | 1 kHz |
| 低通 | 6 kHz |
| 衰减 | 180 ms |
| 失真 | drive 6 dB（并行 30%） |
| 混响 | 0.6 s，wet 12% |
| 侧链 | −4 dB |

#### `hat_closed` / `hat_open`

| 参数 | 闭 | 开 |
|---|---|---|
| HP | 7 kHz | 6 kHz |
| 衰减 | 40 ms | 250 ms |
| sizzle 层 | 9 kHz BP，−12 dB | 8 kHz BP，−10 dB |

#### `rumble_bass`

- 按 2.3 的 5 步；默认 128 BPM，gate 1/16（117 ms），HP 30 Hz / LP 200 Hz。

### 8.2 需要新增/改造的模块

1. **`KickDesigner`（改造）**：拆 sub / body / click 三层，pitch envelope 三参数（start、end、time），内置 `kick_rave` / `kick_hardstyle` 两个宏。
2. **`LayeredBass`（新增）**：sub/mid 分频（默认 150 Hz），mid 层独立失真与低通包络。
3. **`SupersawVoice`（改造）**：unison 数、detune 音分、stereo detune 三个参数；超过 20 声部自动降级。
4. **`EnergyCurve`（新增）**：按 5.4 的表校验 RMS/LUFS/真峰值；不达标给出具体 "加 4 dB @ 60 Hz" 这类建议。
5. **`ThinnessCheck`（新增校验器）**：四频段能量检查（40–80 / 150–300 / 2–5k / 8–12k），任一频段低于阈值就在生成结果里标红。
6. **`BeeperDetect`（新增校验器）**：命中 6.2 的 6 个特征中 ≥ 2 个 → 自动插入 6.3 的处理链。
7. **`RiserImpact`（新增）**：riser 4–8 小节 + gap + impact，参数见 5.2/5.3。

### 8.3 优先级

| 优先级 | 改动 | 理由 |
|---|---|---|
| P0 | KickDesigner 三层 + ThinnessCheck | "薄/提示音"是最常见差评来源 |
| P0 | LayeredBass | 低频决定"有没有劲" |
| P1 | SupersawVoice + RiserImpact | Drop 是否"炸" |
| P1 | EnergyCurve | 段落能量自动化 |
| P2 | rumble_bass / screech | 细分风格，后面再加 |
