## 每个预设的参数（SoundProfile）

| 字段 | 含义 | 影响 |
|---|---|---|
| `kick` | `punch / hard / deep / click / rave` | 决定鼓组 preset → kick 的 pitchDecay、失真量、click 强度 |
| `snare` | `crack / clap / rim` | 军鼓噪声频段与 body 力度 |
| `hat` | `tight / bright / loose` | 镲的高通频率与衰减 |
| `drive` | 0–1 总线失真 | Hardstyle 0.72 / Chaos 0.85 / EDM 0.28 |
| `reverb` | 混响送出 | Pad 0.42–0.55，鼓 0.1–0.12 |
| `delay` | 延迟送出（3/16 附点） | 主音 0.12–0.38 |
| `chop` | 是否加人声切片轨 | 司凤/鬼畜/Hyperpop/Chaos 为真 |
| `chopRate` | 每拍切几刀 | 8 = 32 分音符（默认） |
| `structure` | 段落骨架 | 决定前奏/铺陈长度 |
| `dropBars` | Drop 长度 | 4 或 8 小节 |
| `subHz` | 低频重心 | 44–52Hz（Hardstyle 最低） |

## 落到发声层的具体做法

### 鼓组（`createDrums`）

- **Kick 三层**：`MembraneSynth` body（pitchDecay 48–110ms，octaves 6–8）+ `MonoSynth` sine sub（240ms 衰减）+ `NoiseSynth` click（12ms，2.6kHz 高通）。Hardstyle 额外过 0.5 驱动。
- **Snare 三层**：pink 噪声过 1.75kHz 带通 + `MembraneSynth` 鼓皮（90ms）+ 5.2kHz 高通 crack（8ms）。
- **Clap 三连击**：同一噪声源在 0 / 12 / 26ms 触发三次，带通 1.25kHz——单次触发会像"啪"，三次才像拍手。
- **Hat**：8.4–9.2kHz 高通，28–42ms 衰减；Open hat 220ms。

### 贝斯（`createBass`）

sub 与 mid 分两层：sub 走正弦（-4dB），mid 走锯齿/fatsaw，经 `WaveShaper`（tanh）与低通滤波包络。
- acid：Q=8、滤波包络 4.2 个八度（303 味）
- hard：drive 0.42
- e808：只走 mid 层正弦 + 滑音，不叠 sub
- reese：3 层 fatsaw spread 22

### 主音（`createLead`）

3–5 层 detune 的 `fatsawtooth`（spread 16–32）+ 低通（4.6–7.6kHz）+ `Chorus` + 延迟送出。
- siren（司凤）：额外加 `Vibrato(5.2Hz)` + `Distortion(0.35)`，Q=6 的带通式"怪叫"
- hard：drive 0.55，滤波 4.6kHz
- hyper：`pulse` 波 + 合唱 wet 0.5

### 人声切片（`createVocalChop`）

不采样、不侵权：用**共振峰合成**——锯齿波经 3 个带通（元音 a=730/1090/2440Hz，e/o/i 各一组），
加 5.6Hz 颤音与轻失真。每个切片 60–220ms，按 32 分音符排成"邦吧邦吧"的节奏动机。

### 总线（`SongPlayer`）

`EQ3(low +2dB @200Hz, high +1.5dB @3.2kHz)` → `Compressor(-18dB, 2.5:1)` → `Limiter(-1dB)`。
离线渲染（`render.ts`）用同一条链，所以导出的 WAV 与实时播放一致。

## 怎么新增一个风格

1. 在 `styles.ts` 的 `EXTRA_GENRES` 里加一条（填齐 12 个字段）；
2. 若用到新的 preset 名，在 `voices.ts` 对应分支里加一个 case；
3. `npm test` 与 `npm run build:file`；
4. 用 `scripts/render-samples.mjs` 渲染 8 小节试听。
