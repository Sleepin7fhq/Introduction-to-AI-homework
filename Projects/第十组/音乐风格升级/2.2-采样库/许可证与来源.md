# 许可证与来源清单

## 结论

**全部 52 个采样由本项目生成，不含任何第三方音频。**

| 项 | 值 |
|---|---|
| 许可证 | CC0-1.0（项目自制） |
| 允许商业使用 | 是 |
| 需要署名 | 否 |
| 可再分发 | 是 |
| 采样率 / 位深 | 48000 Hz / 16 bit |
| 声道 | 立体声（双声道同值） |
| 归一化 | 峰值 −1.0 dBFS，首尾 3ms/12ms 淡入淡出 |

每条 manifest 记录都带：`file / category / kind / duration / sampleRate / channels /
rootNote / bpm / tags / source / author / license / commercialUse / attributionRequired`。

## 生成方法（可复现）

| 类别 | DSP 做法 |
|---|---|
| Kick | 正弦 + 指数音高包络（118→44Hz 等）+ 3.5ms 噪声 click（2.2kHz 高通）+ tanh 软削波 |
| Snare | 粉红噪声（1.8kHz 带通，指数衰减）+ 165–320Hz 鼓皮正弦 + 5.2kHz crack |
| Clap | 同一噪声在 0 / 12 / 26ms 触发三次，1.25kHz 带通 |
| Hat / Cymbal | 6 个非谐方波（1 / 1.47 / 1.83 / 2.31 / 2.68 / 3.04 倍频）+ 高通 + 低通 11–12kHz |
| Sub / Reese / Hard Bass | 正弦+二次谐波 / 双失谐锯齿 / 强失真锯齿 + 低通 |
| Lead | 3–7 层失谐锯齿（supersaw）+ 低通 + 包络 + 驱动 |
| Pad | 5 层失谐锯齿 + 慢起音 + 低通 |
| Vocal Chop | 声门脉冲串 → 3 个共振峰带通（a/e/i/o/u）→ 8ms 噪声爆破模拟 /b/ 辅音 |
| Riser | 分段带通扫频（300Hz→9kHz）+ 渐强 |
| Impact | 90→38Hz 下滑正弦 + 低通噪声 |
| SFX | 扫频正弦（laser）/ 多谐方波+颤音（airhorn）/ 抖动正弦（boing）/ FM 钟（ding） |

## 被拒绝的来源（以及为什么）

| 来源 | 拒绝原因 |
|---|---|
| MusicRadar SampleRadar | CDN 的 TLS 在本机被拦，无法下载；其许可也限制"以采样形式再分发" |
| Freesound | 无需鉴权只能拿到 MP3 预览；按要求不把预览当素材 |
| archive.org `elorwav-drum-kit` | 标记 CC0 但描述明确禁止分享，权利冲突 |
| Wikimedia Commons | 关键词检索无 CC0/PD 命中 |
| B 站视频音轨 | **从未尝试**：明确禁止，且属侵权 |

## 如果以后引入外部采样

必须补齐：来源 URL、作者、许可证类型、是否商用、是否需署名，并写进 `manifest.json`。
CC-BY-NC 一律不得作为默认素材（可能涉及商用发布）。
