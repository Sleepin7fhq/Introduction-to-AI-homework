# 修改前后对比

同一句热梗「老板画的饼，很燃，高能 drop」，8 小节，分别用三种风格渲染。
样本目录：`音乐风格升级/样本/`

| 版本 | A 普通 EDM | B 司凤 / 鬼畜 | C Hardstyle |
|---|---|---|---|
| 改前 | `before/A-EDM-before.wav`（house 124） | `before/B-Sifeng-before.wav`（sifeng 113） | `before/C-Hardstyle-before.wav`（rock 113） |
| 改后 | `after/A-EDM-after.wav`（classic_edm 128） | `after/B-Sifeng-after.wav`（sifeng_rave 172） | `after/C-Hardstyle-after.wav`（hardstyle 152） |

> 改前没有 Hardstyle/司凤专用预设，只能用最接近的 `house / sifeng / rock`；
> 改后是真正的三套编制。BPM 变化本身也是"风格真的生效"的证据。

### 怎么读这些数字

- **B 改后（司凤）**：频谱重心 1188→1490 Hz、presence 7.5%→9.2%、air 3.7%→6.8%——
  切片轨（共振峰人声）与 siren 主音把中高频撑起来了，这就是"怪叫感"的来源。
- **C 改后（Hardstyle）**：sub 31%→36%、瞬态 1.22→1.76/秒、重心 1050→826 Hz——
  更重、更"砸"，符合 Hardstyle 的 kick 主导。
- **A 改后（EDM）**：重心 902→1097 Hz、air 2.9%→3.7%，低频仍然最重（44%），是"宽而亮"的方向。
- 三首 RMS 都提高了 2–8 dB（总线加了驱动与限幅），**这部分是响度提升，不等于音质提升**——
  真正的变化看频谱分布与瞬态密度。

## 代码上到底改了什么

| 问题 | 改前 | 改后 |
|---|---|---|
| Kick 没有冲击 | 单层 MembraneSynth + 噪声 click | 三层：body（pitchDecay 48–110ms）+ sine sub + click |
| Snare 像拍手 | 单层噪声 | 噪声 + 鼓皮 + 5.2k crack，三件套 |
| Clap 太假 | 单次触发 | 0/12/26ms 三连击 |
| Bass 单薄 | 单个 MonoSynth | sub + mid 双层，mid 过 tanh 驱动与滤波包络 |
| Lead 像提示音 | 单振荡器 saw | 3–5 层 detune + 滤波 + Chorus + 延迟 |
| 没有效果差异 | 所有轨固定混响送出 | 每轨独立 reverb/delay 送出，随风格变化 |
| 总线单薄 | 直接进压缩 | EQ3（+2dB 低频 / +1.5dB 高频）→ 压缩 → 限幅 |
| 没人声 | 无 | 共振峰合成人声切片（32 分音符节奏动机） |
| 风格不生效 | style 覆盖被重新推断覆盖 | 显式传 genre，锁定风格同时定 BPM/调式/编制 |

## 必须说明的局限：这是**客观测量**，不是听感结论

本环境没有可用的音频输出设备，我**无法用耳朵确认**"好不好听"。上面的数字能证明：

- 能量分布变了（不再是单薄的单一频段）；
- 瞬态密度变了（鼓组真的在"打"）；
- 司凤样本确实多了中高频的切片层。

但它**不能证明**"听起来像 B 站鬼畜"。这件事必须你来判断，三个 WAV 就是为此准备的。
如果你听完仍觉得某一段"塑料"，最可能的三个原因是：

1. 共振峰人声只有元音、没有辅音，缺少"邦/吧"的爆破感（见 05 第一条）；
2. 没有侧链，kick 与 bass 在低频打架；
3. Lead 的 detune 层数不够（现在 3–5 层，Trance 常见 7–9 层）。
