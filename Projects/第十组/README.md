> AI 音乐工作站：把一个网络热梗，做成一首能蹦的歌——而且产物是**可编辑的音符工程**，不是黑盒音频。

## 一、怎么运行（评审老师看这里）

### 最快：双击单文件版

双击 **`dist/index.html`** —— 不需要安装、不需要服务器、不需要联网。

> 注意：这种打开方式下浏览器会拦截采样文件，音色会退回合成器版本（功能完整，只是音色旧）。

### 完整体验：起个本地服务

```bash
npm install
npm run dev      # 打开 http://127.0.0.1:5173/
```

这样会加载 `public/samples/` 里的 52 个 one-shot 采样，听到的就是最新音色。

### 可选：本机 AI 音频（ACE-Step）

需要本机有 ACE-Step 1.5 服务（`http://127.0.0.1:8000/health` 返回 ready）。
未启动时界面会如实显示「不可用」，生成自动走本地算法引擎——**不会伪造 AI 音频**。

## 四、关于素材与版权

- 52 个采样由本项目用 DSP 合成（`scripts/build_samples.py` 可复现），**CC0，可商用**；
- 未使用任何 B 站/商业歌曲音轨；
- ACE-Step 模型权重未随仓库分发；
- 热梗知识库只引用名称/语境与来源链接，未搬运原视频。

## 五、本仓库未包含的内容（体积原因）

`node_modules/`、ACE-Step 模型（约 9.4GB）、构建缓存、改前样本 WAV。
