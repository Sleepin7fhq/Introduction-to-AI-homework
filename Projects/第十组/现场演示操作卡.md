# 现场演示操作卡 · DSH Studio 2.0

> 一页纸，照着做。全程不需要联网下载任何东西。

---

## 一、启动（约 30 秒）

1. 双击根目录 **`启动演示.bat`**
2. 等它打印 **`就绪！`**（模型加载约 15–20 秒，最多等 2 分钟）
3. 浏览器自动打开 **http://127.0.0.1:5173/**
   （没自动开就手动输入这个地址）

**开场前自查一眼**：右上角「ACE-Step 1.5（本机）」是 **绿色「可用」**。

---

## 二、演示（5 分钟，四步）

| 步骤 | 操作 | 看点 |
|---|---|---|
| 1. AI 生成 | 写 `techno，凌晨两点还在改代码，128 BPM` → 小节改 **8** → 点**生成音乐** | 约 10 秒出现蓝色「AI 音频」条 → 点播放 |
| 2. 可编辑 | 引擎切 **本地符号引擎** → 风格选 **司凤 Rave / Hardstyle** → 再点**生成音乐** | 五轨音符 + 采样鼓组，和弦 `Gm7 → Fmaj7…` |
| 3. 改 | 左栏「鼓组」点 **M** 静音 → 再点回来；拖「贝斯」推子 | 能单独摘掉一条轨 |
| 4. 收尾 | 点右上**导出 MIDI**；再切 **Meme-to-Rave** 输入 `早八打工人` → 找 → 生成 | 听 Drop，读大屏 `06:59 · 再睡五分钟` |

**要讲的一句话**：模型给波形（第 1 步），算法给结构（第 2 步），人能改结构（第 3 步）。

---

## 三、备用（按顺序，别慌）

| 现象 | 处理 |
|---|---|
| ACE 徽章变灰 | 点「重新探测」；还不行就切「本地符号引擎」继续演示 |
| 想放真实 AI 音频但服务挂了 | 右栏「**预生成真实音频**」→ 点 Techno 128 / 早八 Rave 138 |
| 网页打不开 / 服务都起不来 | 双击 **`dist\index.html`**（单文件版，不需要任何服务） |
| 点播放没声音 | 先点一下页面任意位置，再点播放 |
| 页面白屏 | 屏幕会显示红色错误横幅，按提示刷新；仍不行换单文件版 |

**永远可用的底线**：`dist\index.html` + 右侧两条预生成 WAV。这两样不依赖服务、不依赖网络。

---

## 四、关闭

关掉两个最小化的命令行窗口：

- **ACE-Step 服务**
- **DSH Studio 前端**

（关窗口即停止；模型和素材都留在磁盘上，下次启动不用重新下载。）
