# AI＋校园建筑互动导览

为**中大院、体育馆和四牌楼校区图书馆**提供本机导览。参观者可以直接选楼，也可以上传照片、核对识别结果，再阅读讲解和连续追问。每栋建筑配有两张实拍参考照，另外七张照片用于独立测试。

三张卡已收录 2026 年 11 月 20 日人工核查的校史资料。建造年代、人物与历史用途可逐条打开出处，外观观察注明所用实拍。C 组建筑统一命名为“四牌楼校区图书馆”。[资料核查记录](docs/建筑资料核查_2026-11-20.json)

本目录为课程作品源码，可直接浏览和运行。配置模板不含密钥；未配置 API 时可使用离线模拟。真实识图和联网搜索需要在本机配置百炼账号。

## 在本机打开

首次运行请先按下方步骤安装 Python 环境和依赖。macOS 完成安装后，可双击 [启动导览.command](启动导览.command) 打开；Windows 使用下方命令启动。服务只监听本机，使用期间保留终端窗口，结束时按 Control+C。

保持默认的 **离线模拟**，从“按名称选择”选楼并生成讲解。可以问“中大院是哪年扩建的？”“泰戈尔和体育馆有什么关系？”或“图书馆外墙的八字是什么意思？”。问“2026 年周日几点开放？”时，页面会提示现有资料不足。要排练照片流程，在“从照片识别”上传一张测试照，点击识别后手动选择并确认对应建筑。真实视觉模型的比对结果见测试交接说明。[独立测试照片](data/test_images/)

### 在另一台电脑安装

使用 Python 3.12，在项目目录打开终端。首次安装依赖需要联网，安装完即可离线演示。虚拟环境须在每台电脑上单独创建。

**macOS 或 Linux**

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py
```

**Windows PowerShell**

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

浏览器没有自动弹出时，打开终端显示的本机 URL。默认端口是 8501。

## 更新建筑资料与配置模型

1. 将三栋楼的正式名称、可见特征、可讲述的事实和各自出处填入 [建筑资料](data/buildings.json)。每条事实都可指向官网页面或小组的现场记录。完成替换后，把对应卡的 `placeholder` 改为 `false`。[资料填写说明](docs/资料填写.md)
2. 将每栋楼的一至两张已知参考照片放入 [参考图目录](data/reference_images/)，把文件名写到本楼的 `reference_images`。另留不同角度的照片供 C 上传测试。暂缺参考图时，接口仍可依据已填写的外观线索尝试判断。
3. 复制 [无密钥配置模板](config.example.toml)，在同一目录命名为 `config.toml`，用文本编辑器在本机填写三个模型字段。真实配置与独立环境已加入 Git 忽略规则。

| 配置项 | 填写内容 |
| --- | --- |
| `API_KEY` | 所选服务商为本组签发的密钥，仅保存在本机 |
| `BASE_URL` | 服务商对应地域或业务空间的兼容接口基础地址，程序会追加 `/chat/completions` |
| `MODEL_NAME` | 该账户可用、支持多图输入和非流式 Chat Completions 的视觉模型名 |

模板采用阿里云百炼北京地域的业务空间地址和 `qwen3-vl-plus` 作示例。`{WorkspaceId}` 须替换为所用空间 ID，模型权限以该账户为准。也可按其他兼容服务商的官方文档替换三个字段。[百炼 OpenAI Vision 接口](https://help.aliyun.com/zh/model-studio/qwen-vl-compatible-with-openai) · [图片与多图输入示例](https://help.aliyun.com/zh/model-studio/vision)

填好配置后，在界面选择 **真实 API**。切换模式和上传预览均在本机完成。可先手选一栋楼生成简短讲解，再上传一张新照片验证视觉输入。服务商按账户规则处理已发出的请求，超时后由操作者决定是否重试。

## 技术流程

| 操作 | 程序如何处理 |
| --- | --- |
| 导入照片 | Pillow 解码 JPG/PNG、校正 EXIF 方向、处理透明背景，重新编码为 JPEG。待识别图长边最多 1280 像素，参考图最多 768 像素。单个原文件上限 12 MB、3600 万像素。上传照片在会话内存中处理。 |
| 识别并确认 | 真实模式把候选名称、外观线索和带建筑编号的参考图放在前面，最后单独标出待识别图。程序校验返回编号及理由。证据不足可返回“无法确定”。游客确认或更正后才能生成讲解。 |
| 导览与追问 | 常规讲解按资料卡编排，简短版优先介绍建筑年代或原用途及一处可观察的细节，详细版最多六条。真实模式在相应范围内选择事实编号。追问可使用本卡全部事实，并携带当前讲解和最近六轮问答。页面在各条原句下展示相应出处，资料不足时说明缺口。 |
| 离线模拟 | 实拍照片由参观者手动选楼。讲解取资料原句，追问按关键词查找，也支持“再说一遍”。使用原始占位模板时，可用内置示意图演示文件匹配。 |
| 请求与会话 | 识别发送一次请求；生成或追问若返回非法格式或资料编号，最多额外纠正一次。资料不足时按下述规则自动搜索。网络、权限和额度错误不自动重试。成功的识别和已生成的同长度讲解保存在当前会话中。更换建筑、模式、导览方式或待识别图会清理旧结果。刷新浏览器会开启新会话。 |

界面与会话在 [app.py](app.py)，模型调用与模拟逻辑在 [ai_service.py](ai_service.py)，材料校验与图像处理分别在 [guide_data.py](guide_data.py) 和 [photos.py](photos.py)。错误提示区分配置、文件、超时、权限、额度以及返回格式异常。应用不打印密钥、请求头或服务商响应正文。

## 联网补充

真实 API 模式下，讲解或追问遇到资料不足（部分覆盖或未记录）时，会自动调用百炼搜索；资料已充分覆盖时仍可点击“联网补充”。复用本机密钥，默认使用 `qwen-plus`，识图模型保持不变。配置文件支持：

```toml
SEARCH_ENABLED = true
SEARCH_MODEL = "qwen-plus"
```

搜索默认限定东南大学官方站点，结合学校、校区、建筑名和本次问题补充回答。当前回复与补充信息之后统一展示去重的小字号来源链接，并标注检索时间。引用链接仅取自服务商实际返回的搜索来源，模型自行生成的 URL 不会加入来源列表。来源不含发布日期时不推算日期，检索时间不代表发布日期。

每条回复只自动搜索一次；成功结果保存在当前会话，控件重跑或切换讲解长度不会重复搜索。失败时保留本地回答，可点击“重试搜索”，不会无限自动重试。更换建筑或照片会清除旧结果。联网结果不会自动写入本地资料库；模型整理仍可能出错，应核对原文。

搜索成功后直接显示答案，不再展示资料不足提示和完成按钮。检索时间合并在末尾的小字号来源区。每句必须带有效搜索引用；无引用、无效引用或内部知识库说明所在的句子不会展示，避免仅隐藏标记却保留无依据的内容。

仅支持百炼官方 compatible-mode/v1 基础地址，程序转换为同地域的 DashScope 原生搜索接口。账号需有搜索模型的调用权限，调用按平台规则计费。没有实际来源、缺少有效引用或请求失败时，明确提示并保留原讲解，不把模型记忆回答当搜索结果。

[百炼联网搜索文档](https://help.aliyun.com/zh/model-studio/web-search/)
