## D 的三分钟操作顺序

| 时间 | 画面与讲述 |
| --- | --- |
| 0:00–0:25 | 提出参观者的问题，“眼前是哪栋楼，它有什么值得了解的地方？”交代三栋候选和当前模式。 |
| 0:25–1:15 | 上传一张中大院测试照，展开候选参考图。真实模式展示模型原判和确认步骤，离线排练时手动选中大院并确认。 |
| 1:15–2:15 | 生成简短讲解。追问一条有出处的事实，再问一项卡中未写的内容，展示来源或资料不足提示。 |
| 2:15–3:00 | 切换另一栋楼，展示旧对话已清空。用实测记录说明照片角度或资料覆盖范围的影响，交代四人分工。 |


## 最新交付验收（2026 年 11 月 20 日）

结论：可作为人工智能导论课的本地演示版交付。已检查依赖，43 项自动化测试全部通过；修复后真实 API 的 15 项交互检查全部通过。真实模型为本机配置的 qwen3.7-plus，联网补充使用 qwen-plus。

- 7 张独立实拍首次识别：T01–T03 均识别为中大院，T04–T06 均识别为体育馆；T07 图书馆遮挡照返回“无法确定”。本组 6/7 正确识别，1/7 拒识，没有误认成其他候选。该结果仅适用于这组照片，不代表普遍识别准确率。
- 空白图对照返回“无法确定”。首次识图单次耗时为 3.4–33.4 秒（含空白图）；课堂应预留等待时间。
- 真实交互检查覆盖三栋楼生成讲解、中大院连续追问、体育馆资料不足时自动搜索、图书馆八字校风追问与详细讲解、切楼清空旧对话、页面控件重跑不重复请求、离线备用模式。
- 首轮发现图书馆简短讲解偶发非法编号：模型返回数字 1、2，而非资料字符串编号。已明确允许编号，并限制仅纠正一次格式错误；复测通过。未知编号不会被猜测转换，网络及权限错误不会自动重试。
- 已同步最新名称、紧凑来源展示和自动搜索行为。没有有效搜索引用的句子不展示；搜索失败时可手动重试。

课堂主流程建议选用 T03 或 T05；T07 用于说明遮挡时无法确定、需要人工确认的边界，不作为必定识别成功的示例。其他非候选建筑照片尚未做真实接口实测，空白图不能代替此类验证。
