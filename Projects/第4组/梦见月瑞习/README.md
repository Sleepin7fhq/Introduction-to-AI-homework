# 梦见月瑞习 · 可运行 Demo

> 你教我，我装傻。

梦见月瑞习是一个能当场跑起来的 AI 学习搭子；「梦见月」是里面那个会装傻的 AI 学生。
你讲一个概念，它先装懂（误解），再追问，最后给你一张四维诊断卡。

**零依赖**：只要一个 Python 3，不需要 `pip install` 任何东西。没有 API Key 也能完整演示。

---

## 一、30 秒启动

### 本机

```bash
cd demo
python3 server.py        # Windows 下双击 start.bat
```

浏览器打开 **http://127.0.0.1:8770**。零依赖，不用 `pip install`。

### 换一台电脑

整个 `demo/` 文件夹拷过去就行，**没有别的依赖，只要那台机器上有 Python 3**。

1. 拷文件夹（U 盘、微信传压缩包都行）
2. 双击 `start.bat`（Windows）或 `./start.sh`
3. 浏览器打开 http://127.0.0.1:8770

如果没有 Python：去 python.org 装一个，安装时**务必勾选 "Add Python to PATH"**，三分钟。

> 现成的压缩包：项目根目录的 `梦见月瑞习-demo.zip`（0.1 MB，不含 API Key）。
> 想带着 Key 走，把 `demo/config.json` 一起复制过去。

### 课堂模式（扫码进课堂）

```bash
start-lan.bat            # Windows，双击
./start-lan.sh           # Mac / Linux
```

会自动打开一个全屏页面：**大二维码 + 网址 + 实时在线人数**。
同学拿手机一扫就进站，屏幕上的「已有 N 人在线」会随人数实时变化。

页面地址：http://127.0.0.1:8770/classroom

- 二维码是服务端用内置的 `vendor/qrcode` 生成的，**不联网、不依赖任何在线服务**
- 在线人数靠每个页面每 10 秒发一次心跳，25 秒没动静就算离线
- 如果只在本地跑（没开 `DSH_DEMO_HOST=0.0.0.0`），这个页面会直接告诉你「手机扫不开」并给出改法

### 让同学也能打开（局域网模式）

```bash
DSH_DEMO_HOST=0.0.0.0 python3 server.py    # Windows 双击 start-lan.bat
```

启动时会打印类似 `http://192.168.1.23:8770` 的地址，**同一个 Wi-Fi 下的手机、平板、
别人的笔记本直接打开就能用**——答辩时可以让全班同时玩。

注意三点：
1. **要在 Windows 上跑，不要用 WSL。** WSL 里拿到的 IP 是虚拟网卡的，外面连不上。
2. 打印出多个地址时逐个试，装了 VPN 或虚拟机网卡会多出几个。
3. 打不开先看 Windows 防火墙有没有放行这个端口。

> 局域网模式下，别人也能访问你的页面（页面本身没有登录）。答辩场合没问题，
> 但别在公共网络上长时间开着。修改 API Key 的接口已经限制成只允许本机调用。

## 二、接入真模型（两分钟，强烈建议）

### 第一步：拿一个 Key

| 平台 | 注册地址 | 说明 |
|---|---|---|
| **DeepSeek** | platform.deepseek.com | 最省事。注册 → 充值（10 元够跑几百次）→ 「API keys」→ 创建 |
| **硅基流动** | siliconflow.cn | 注册通常送额度，有免费小模型 |
| **阿里百炼** | bailian.console.aliyun.com | 新用户有免费 token 额度 |
| **智谱** | open.bigmodel.cn | `glm-4-flash` 有免费档 |

创建 Key 后**只显示一次**，当场复制走。

### 第二步：填进界面

1. 打开 http://127.0.0.1:8770
2. 点右上角那个「引擎 · 本地规则」徽标
3. 先点平台名（DeepSeek / 硅基流动 / 阿里百炼 / 智谱），地址和模型名会自动填好
4. 粘贴 Key
5. 点 **「测试连接」** —— 会真的发一个请求过去
6. 看到 `连接成功 ✓ 模型 deepseek-chat，耗时 xxx ms` 就点 **「保存并启用」**

右上角变成「引擎 · 大模型」就切过去了。**下次启动自动读取，不用再填。**

### 出问题对照表

| 提示 | 原因 |
|---|---|
| 401 invalid api key | Key 没复制全，或者已经被删了 |
| 402 insufficient balance | 余额不足，去平台充值 |
| 403 | 这个 Key 没有该模型的权限 |
| 404 | 接口地址或模型名写错了，点一下平台预设重填 |
| 连不上、超时 | 网络/代理问题，换手机热点试试 |

### 三种配置方式（优先级从高到低）

1. **界面里填**（推荐）—— 存到 `demo/config.json`
2. **直接改 `config.json`**：

```json
{
  "api_key": "sk-你的key",
  "api_base": "https://api.deepseek.com",
  "model": "deepseek-chat"
}
```

3. **环境变量**（要注意：必须在**启动服务的那同一个终端**里设，在 Windows 设了却去 WSL 启动是不生效的）

```bash
export DSH_DEMO_API_KEY=sk-xxxx
export DSH_DEMO_API_BASE=https://api.deepseek.com
export DSH_DEMO_MODEL=deepseek-chat
```

> ⚠️ `config.json` 里是你的私钥，已写进 `.gitignore`。**别提交到 GitHub，也别发给同学。**

### 没 Key 会怎样

自动走本地规则引擎，功能完整、能演示，只是追问没那么灵活。Key 失效或欠费时也会自动降级，并且**冷却 60 秒**——不会让现场每个请求都卡 25 秒。

## 三、现场 4 分钟怎么用

| 时间 | 动作 |
|---|---|
| 0:50 | 请一位同学上台，选「线性代数 → 矩阵的秩」 |
| 1:00 | 点「填一段示例」（或让同学自己讲），点「开始教它」 |
| 1:10 | 大屏念出 AI 的误解：「秩就是这个矩阵里非零行的个数，对吧？」 |
| 1:30 | 念出追问：「那为什么做初等行变换、行数一行没少，秩却不变呢？」 |
| 2:00 | 同学回答，AI 再追一问；答不上来就点「跳过，我讲不清了」 |
| 3:00 | 点「直接看诊断卡」，大屏出现雷达图和四条证据 |
| 3:20 | 指着证据念一句：「你看，它扣你分用的是你自己的原话。」 |

**兜底方案**（万一现场紧张或网络抖动）：

打开 **http://127.0.0.1:8770/?auto=1**，它会自己演示一遍，全程不需要操作。

## 五、练习怎么用

**配置**：左上选科目（线性代数 / 高等数学），中间点星星选难度（1 基础 → 5 挑战），
右边切模式（单题 / 试卷）。

**单题练习**：点「出一道题」→ 作答 → 「提交批改」→ 立刻看到得分、点评、错在哪、参考答案、
可展开的完整解析。

**试卷练习**：点「生成试卷」→ 一次出 5 题（3 选择 + 1 填空 + 1 计算）→ 全部做完点「交卷批改」
→ 总分 + 每题得分 + 逐题解析。

**大题可以拍照**：计算题那栏除了写文字，还能上传解题过程的照片（点一下或直接拖进去）。
上传前浏览器会自动压到 1400px、JPEG 0.82，一般 30-60 KB。AI 会先读出你写了什么，再判分。

**从文件出题**：练习页顶部可上传 PDF / Word(.docx) / PPT(.pptx) / 图片 / txt。
文件会原样转成 base64 附件，随 chat/completions 请求一起发给当前配置的模型，由模型自己读题、
再仿照出相似题——服务端**不做本地文字提取**。
- 需要接口/模型支持 `file` 内容块（PDF/Word/PPT）；纯文本模型（如 deepseek-chat）不支持，
  页面会直接显示返回的错误。图片需要模型支持视觉（如 qwen-vl、glm-4v）。
- 文件上限 8 MB；图片上传前浏览器会压到 1600px、JPEG 0.85。
- 识别到几道原题、生成了几道相似题，页面顶部会给出提示。

**个人错题集**：做错的题（选择题答错，或大题得分低于 80%）自动收进浏览器本地的错题集，
只保存题目、选项、参考答案和解析，最多 100 题；练习页点「错题集」查看，不做统计等其它功能。

**判分规则**：
- 选择题在本地判，不花 token，也不会误判
- 填空和计算交给模型，按「答案对过程全 / 答案对过程省 / 思路对算错 / 思路错」四档给分
- 每条扣分都会说清楚扣在哪

**数学式子**：全用 Unicode（x²、√3、λ₁、∫），不依赖 MathJax，断网也能正常显示。

**注意**：AI 出的题和判分都可能有误差，当练习用没问题，别当标准答案背。

## 六、一心净土怎么用

打开 `/static/pomodoro.html`（首页第三张卡片）。单文件纯前端，数据只存浏览器 localStorage，不联网。

- **计时**：默认 25 分钟专注、5 分钟休息，可在「设置」改成 1–120 / 1–60。支持开始、暂停、继续、
  提前结束、放弃；提前结束或放弃都要选原因（任务完成 / 临时有事 / 不想学了 / 其他），
  都不计为完成，但已经产生的有效专注会保留。
- **分心**：页面隐藏超过 5 秒记 1 次；超过 2 分钟自动暂停并提示。暂停期间切屏不计分心，
  隐藏少于 5 秒不计分心、也不计有效专注。
- **任务**：新建任务（名字 + 预计番茄数），开始前可选绑定；一个任务可绑多个番茄，
  完成由你手动标记，不自动改状态。
- **背景音**：棕噪音、风扇声两种，Web Audio 实时合成，不加载音频文件；音量可调，
  播放失败不影响计时。
- **报告**：今日/本周切换，展示有效专注、番茄完成率、分心次数、任务完成率、评分与三项得分、
  本周 CSS 柱状条、分心小时分布、任务投入和一句规则生成的总结。
  评分 = 55% × 有效专注率 + 25% × 分心控制率 + 20% × 任务完成率；无绑定任务时按 55 : 25 归一化。
- **边界**：刷新页面不恢复未完成的计时，已结束的会话会保留；清空数据需二次确认，
  只清 `pomo.*` 这几个 localStorage 键，不影响站点其它数据。

## 七、梦见月是怎么工作的

**三段式**（对应报告 2.5.2）：

1. **对抗性复述** —— 从你的讲解里挑出最关键的模糊点，构造一个「最合理的误解」。
   概念包里的 `traps[0].say` 就是每个概念最典型的错误理解，比如「秩 = 非零行的个数」。
2. **苏格拉底追问** —— 围绕边界、反例、机制问三轮，每轮只问一个，不跑题。
3. **可解释诊断** —— 四维打分（清晰度 / 边界感 / 机制感 / 迁移力），每条扣分必须引用你的原句。

**本地引擎**不是随机说话：它分析你文本里的结构特征——有没有定义句、有没有限定条件、
有没有因果连接词、有没有举例——再对照概念包的误解库，选出最贴的那一问。
所以它问的问题会和你说的话真的对上。

**大模型引擎**把同一套流程交给模型执行，用 JSON Schema 约束输出，解析失败自动回退。

## 八、已知边界

- 本地引擎不会判断你讲得**对不对**，只判断讲得**清不清楚**。这是设计取舍，不是缺陷。
- 概念包目前 30 个，覆盖大一上四门基础课 + 生活常识 + 集成电路入门。
- 分数只作提示，证据才是重点。答辩被问「AI 凭什么打分」时，就答这一句。
- 上传文件依赖模型能力：纯文本模型读不了 PDF/Word/PPT，只支持图片输入的模型读不了文档，页面会显示接口返回的错误。
