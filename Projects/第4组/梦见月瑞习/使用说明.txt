梦见月瑞习 Demo 使用说明
======================

一、启动
  双击桌面快捷方式「启动梦见月瑞习课堂」，或进 bentongxue-demo 文件夹双击 start-lan.bat。
  黑色窗口不要关，关了服务就停。

二、关于 API 与费用
  API Key 只存在这台电脑的 config.json 里，别人看不到（只有 sk-****xxxx 掩码）。
  但别人每点一次 AI，花的是你的额度。
  保护：访客 300 次上限、本机不受限、课堂大屏可一键关访客 AI。
  改额度：config.json 的 visitor_ai / visitor_ai_limit。

三、让别人访问
  1. 先双击 开放端口.bat（管理员确认，允许一次）
  2. 双击 start-lan.bat
  3. 屏幕显示 http://10.x.x.x:8770，别人连同一 Wi-Fi 输入即可
  ★ 电脑必须一直开着、不睡眠；换 Wi-Fi 后地址会变，看屏幕

四、打不开排查
  a) 本机先打开那个地址试试
  b) 自己能开别人不能 → 防火墙，跑 开放端口.bat
  c) 还不行 → 不在同一网络或校园网隔离，改用手机热点

五、功能
  /                         首页
  /classroom                课堂模式（二维码 + 额度控制）
  /static/bentongxue.html   梦见月
  /static/practice.html     练习（线代 / 工数，自动批改）
  /static/pomodoro.html     一心净土（专注 + 任务 + 质量报告）

六、练习模块
  选科目与难度（1-5 星），单题或整卷。计算题可上传解题照片，AI 先读再判。
  AI 出题与判分可能有误差，当练习用，别当标准答案。
  顶部可上传 PDF / Word / PPT / 图片：文件直接交给模型识别，不做本地解析，再出相似题。
  做错的题自动进「错题集」，存在浏览器本地，最多 100 题。

七、一心净土
  默认 25 分钟专注、5 分钟休息，可在页面「设置」里改。
  两种背景音：棕噪音、风扇声，浏览器实时合成，不加载音频文件。
  数据只存在浏览器本地，刷新不恢复未完成的计时；清空数据在设置页，需确认两次。

八、注意
  config.json 里是 API Key，分享前先删掉。
