# 跳跃战舰 · JUMP BATTLESHIP

第17组作业 · 可运行版本（Windows）

## 下载与运行

1. 下载本文件夹里的 `JumpBattleship_Windows.zip`（约 36MB）：
   [点这里下载](https://github.com/Sleepin7fhq/Introduction-to-AI-homework/raw/main/Projects/%E7%AC%AC17%E7%BB%84/JumpBattleship/JumpBattleship_Windows.zip)
2. 解压到任意文件夹，解压后会得到一个 `Windows` 文件夹
3. 进入 `Windows` 文件夹，双击 `跳跃战舰.exe`（或 `启动游戏.bat`）

不需要安装 Unity，也不需要联网。
系统要求：Windows 10 / 11 64 位。

## 操作

| 按键 | 作用 |
|---|---|
| W / S | 前进 / 倒车 |
| A / D | 左转 / 右转 |
| 鼠标 + 左键 | 瞄准 / 主炮开火（按住连发） |
| 空格 | 跳跃（消耗 20% 能量，滞空免疫鱼雷） |
| 按住右键 | 修理 |
| Left Shift | 自由视角，滚轮缩放 |
| F1 | 无敌模式（调试用） |
| Esc | 返回主菜单 |

**目标**：全速向东，抵达目标海域即胜利。

## 出问题了

| 现象 | 怎么办 |
|---|---|
| 双击没反应 | 右键「以管理员身份运行」试一次 |
| 文字显示成方块 | 系统缺中文字体，装一下「微软雅黑」 |
| 画面很卡 | 关掉其它占显存的程序再试 |
| 杀毒软件报警 | Unity 打包程序的常见误报，选择「允许运行」 |
| 解压后找不到 exe | 确认解压的是 `Windows` 文件夹，不是压缩包本身 |
