# SignWindow 手语识别 · 完整版

本目录包含同一项目的两个版本，分别面向不同设备使用。

## 目录结构

```
SignWindow-完整版/
├── 手机版/    # 面向手机（移动端）的手语识别应用
├── 电脑版/    # 面向电脑（桌面端）的手语识别与数据采集工具
└── README.md  # 本说明文件
```

## 手机版（`手机版/`）

面向手机浏览器的手语识别应用，主打轻量、即开即用。

- 入口页面：`index.html`
- 识别能力：实时手语手势识别
- 运行方式：见 `手机版/README.md`

## 电脑版（`电脑版/`）

面向电脑的完整工具集，包含手语识别、骨架序列采集、静态手势实验三个页面。

| 页面 | 入口文件 | 功能 |
|---|---|---|
| 手语识别 | `recognize.html` | 上传视频/摄像头实时识别 203 个手语词 |
| 骨架采集器 | `collector.html` | 录制手语动作，采集训练样本 |
| 静态手势实验台 | `index.html` | 3 类静态手势识别 Demo |

- 运行方式：见 `电脑版/README.md`

## 两个版本的区别

| 维度 | 手机版 | 电脑版 |
|---|---|---|
| 目标设备 | 手机 / 移动端 | 电脑 / 桌面端 |
| 页面数量 | 1 个（识别） | 3 个（识别 + 采集 + 实验台） |
| 模型形式 | 分片模型（assets/model-part-*.bin） | 单文件模型（sign_model_web.json） |
| 数据采集 | 不支持 | 支持（collector.html） |
| 训练样本补充 | 不支持 | 支持 |

两个版本均无需后端，纯前端本地推理，代码未做任何修改。
