# 韩同学演示教程（3 分钟现场演示完整指令）

> 你的任务一句话：**用 3 分钟让老师看到"一个 AI，多个身份"是真的在跑。**
> 本文所有时间、现象、处理办法都来自三轮实测（安全审计 / 演示审计 / 功能验收），不是猜的。

---

## 0. 记住一句话

> 「我们的作品是《小组 AI 助教》——**人工智能+教育**。一句话：**一个 AI，多个身份**。」

四张牌：**身份**（AI 知道为谁服务）→ **权限**（谁能干什么）→ **协作**（时间线接力）→ **记账**（用量成本）。

---

## 1. 演示前一天（在家准备）

1. **装包**：双击 `DSH-Lan-Share-Setup.exe`。若弹 SmartScreen：「更多信息 → 仍要运行」。装完桌面出现「DSH 共享网关」。
2. **启动**：双击「DSH 共享网关」→ 看到「启动完成！」（首次约 2-3 分钟，全程有进度提示）→ 浏览器自动打开登录页。
3. **admin 首登**：`admin / AdminPass!2026` → 会被要求改密 → 设一个好记的（如 `Study!2026`）→ 进入。
4. **配 key**：打开 `http://127.0.0.1:3090/`（DSH 界面）→ 左下/设置里的「模型设置」→ 选 DeepSeek → 填 API key → 保存。
5. **亲手验证身份牌**：在 DSH 界面发一句「回个好」→ 3 秒内看到 AI 回复 → 关掉。**这一步必须做**，做不通就联系组里要 key。
6. **预置权限**（演示时不用现场点）：`/admin` → 「工作区」→ bob 的工作区 → 共享 → **alice=协作、carol=只读** → 保存。
7. **预登录两个标签**（演示时不用输密码）：
   - 标签 A = `http://127.0.0.1:3090/admin/`（admin 管理台）
   - 标签 B = alice 登录后的聊天界面（`http://127.0.0.1:3090/`，用 alice / AlicePass!2026 登录，同样会要求改密）
8. **记下局域网地址**：启动输出里有 `局域网入口：http://192.168.x.x:3090/login`——现场同学用手机访问这个。

> ⚠️ 改密后**旧标签会失效**（实测），所以改完密再开新标签预登录，演示中途不要再去改密。

---

## 2. 演示当天（提前 20 分钟到场）

1. 开机 → 双击「DSH 共享网关」→ 等「启动完成！」（冷启动 1-2 分钟，有「仍在等待 DSH 就绪…」进度提示，不是卡死）。
2. 检查两个预登录标签还活着（各刷新一次，能看到内容即 OK）。
3. 再发一次「回个好」确认模型通（10 秒）。
4. 万一服务挂了：双击 `stop-all.cmd` → 再双击「DSH 共享网关」→ 等约 2 分钟。**这段时间用来讲 PPT，不慌。**
5. 把 PPT 拷到教室电脑，走一遍翻页。

---

## 3. 三分钟脚本（逐段卡秒 + 每步动作）

### 0:00–0:30 开场（PPT 第 1 页《一个 AI，四个问题》）

> 「我们的作品是《小组 AI 助教》——人工智能+教育。一句话：**一个 AI，多个身份**。
> 大家共用一台 AI 时，会冒出四个问题：**它知道在为谁服务吗？谁能干什么？活儿轮到谁了？花了多少钱？** 我们把四个问题全做进了系统。」

### 0:30–1:00 痛点

> 「现在一个小组要用 AI 助教，要么全组挤一个账号——谁发的不知道、乱用没人管；要么各买各的 key——烧钱。我们解决了这个问题。」

### 1:00–2:00 四张牌现场演示（每张 15 秒）

**① 身份牌（切 alice 标签）**
- 动作：点开标签 B（alice 聊天界面）→ 发「帮我写第一段」→ 等 3 秒。
- 口播：「看，AI 知道在帮谁干活——回复里写着『正在为成员 alice 服务，角色：协作成员』。」
- ❗若 AI 没回复 → 走兜底语（见第 5 节第 1 条），立刻切下一张牌。

**② 权限牌（现场开一个 carol 标签或切到预登录的 carol）**
- 动作：carol 登录后发一条消息。
- 口播：「carol 是只读成员——发消息被当场拒绝：『只读成员不能发送消息』。这不是界面提示，是网关层强制，连路径逃逸（../）也全被拦。」

**③ 协作牌（切 admin 标签 → 「时间线」页）**
- 动作：点左侧导航「时间线」。
- 口播：「活儿怎么接力？——老师发任务、alice 接力、转交接力棒给 bob、bob 接力，全程留在审计时间线上，谁在何时让 AI 做了什么，一清二楚。」

**④ 记账牌（admin 标签 → 「用量」页）**
- 动作：点「用量」。
- 口播：「花了多少钱？——每个人多少条消息、估算多少 token、多少成本、谁超额，账本在这里。四个问题，四个答案，全部是跑起来的代码。」

### 2:00–2:30 技术可行性（30 秒）

> 「技术上：一个纯 Node 网关，不改上游一行代码；密码 scrypt 加盐、路径围栏、全量审计；权限矩阵 32 项实测、演示脚本 16 项全过；打包成 120MB 安装程序，双击装好、自动打开浏览器，**不需要预装任何东西**。」

### 2:30–3:00 收尾

> 「不足我们诚实写在报告里：HTTP 明文（限局域网）、权限三档、用量是估算口径。下一步：权限下沉到 Agent 工具层、接入精确用量。谢谢老师同学，欢迎提问。」

## 5. 故障处理手册（全部来自实测）

| 现象 | 处理 |
|---|---|
| **AI 不回复（key 没了/没配）** | 用兜底语：「为省 key，我们测试时不调真模型；配置 key 后回复就是这样。」→ 立刻切②权限牌（②③④三张牌**不需要模型**，照常演示） |
| 页面卡住/白屏 | 刷新标签；重启服务见下一条 |
| 服务整个挂了 | 双击 `stop-all.cmd` → 双击「DSH 共享网关」→ 约 2 分钟恢复；期间讲 PPT |
| 启动提示「网关已在运行」 | 说明服务已经在跑，直接开 `http://127.0.0.1:3090/login` |
| 标签登录态掉了 | 用 admin / 你的新密码重新登录（演示前**别**再改密） |
| 同学手机连不上 | 让同学用 `http://192.168.x.x:3090/login`（IP 看启动输出）；教室网开了 AP 隔离就连不上，改成手机热点 |
| 双击发了两条 | 不会——同一条消息 30 秒内重复提交只会入队一次（实测修复） |
| 时间不够 | 砍「技术可行性」段（2:00–2:30 可压成一句）；**演示不砍** |

## 6. 兜底语（背这三句）

1. （key 问题）「为省 key，我们测试时不调真模型；配置 key 后回复就是这样。下面看权限牌——这张不需要模型。」
2. （任何冷场）「我们解决的不是造 AI，而是**一个模型、N 个身份怎么安全共享**。」
3. （被问不足）「HTTP 明文、权限三档、用量估算——文档里全部诚实标注，每个都有明确的下一步。」

---

## 7. 最可能被问的 3 个问题（先背）

1. **「AI 在哪？这不就是登录系统吗？」** → 「模型是基础设施；我们解决的是**一个模型被 N 个人共用时的身份、权限、协作、治理**——这正是团队版 AI 工具的核心工程，四个落点都有代码。」
2. **「安全怎么保证？」** → 「密码 scrypt 不落明文；每次读文件都过路径围栏；3080 只在本机回环，同学只能走 3090 这一条受控边界；所有动作进审计。」
3. **「有什么不足？」** → 「HTTP 明文、权限三档、用量估算——诚实标注 + 明确下一步。」

其余 7 问见《答辩问答预演.md》。

- [ ] PPT 在教室电脑上，翻页顺
