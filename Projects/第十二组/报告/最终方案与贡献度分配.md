# 最终方案与贡献度分配（全组唯一事实来源 v1.0）

## 一、项目定位（最终版）

- **作品名**：《小组 AI 助教——"人工智能+教育"》
- **技术名**：DSH 局域网按账号受控共享系统（dsh-team-hub 网关方案）
- **一句话定位**：**一个 AI，多个身份**——DSH 负责 AI 能力，网关负责身份、权限、协作、记账。
- **叙事框架（四张牌）**：
  1. **身份**：AI 知道在为谁服务——共享成员发消息时注入「你正在为成员 X 服务，角色【协作/只读】」；
  2. **权限**：多级权限 chat（协作）/ viewer（只读）+ 路径围栏 + 纯文本守卫；
  3. **协作**：会话转交（接力棒）+ 审计时间线（谁在何时让 AI 做了什么）；
  4. **记账**：每人 token 用量 / 估成本 / 配额超额标红。

## 二、最终架构与功能（事实清单）

- **双进程**：DSH 上游 127.0.0.1:3080（单身份，仅回环，实测局域网连不通）｜ 网关 0.0.0.0:3090（N 账号，唯一安全边界）。
- **技术栈**：纯 Node 网关（node:http/ws/fs/crypto，零重依赖）；scrypt 加盐密码（不落明文）；HttpOnly 会话 cookie；登录节流（5 次失败指数退避）；路径围栏（../、绝对路径、穿越全拦）；WS 流按成员逐帧过滤；全量审计。
- **账号体系**：admin / alice / bob / carol，**首登强制改密**；admin 全权（账号/共享/转交/审计/用量），成员受限。
- **一键交付**：`DSH-Lan-Share-Setup.exe`（120.7MB，自包含 Node v24.16.0，无需预装任何环境）；安装 18–29 秒 / 241 个文件（node_modules 以 3 个 tar 随包、首次启动解压）；启动后**自动打开浏览器**到登录页；`stop-all.cmd` 一键停止（后台隐藏运行，防误关）。
- **已修复的可靠性问题**：事件驱动归属（新会话立即生效，无 5 分钟滞后）；撤销共享主动断开成员 WS；DSH 冷启动超时 6 分钟；排练脚本自愈（自动建会话重建 payload）。
