# DSH 局域网共享服务 — 使用说明

> 本说明教你把这套东西**跑起来、演起来、验起来**。原理与证据不在本文——看同目录的
> 《验证报告》（为什么这么设计、每条结论的出处）与《课堂演示操作流程》（上台照着念的脚本）。

---

## 1. 这是什么

一台机器上跑两个进程，把"只能本机用的 DSH"安全地共享给局域网里的多个账号：

```
浏览器(admin/alice/bob) ──► dsh-team-hub 网关 :3090（0.0.0.0，对外）
                              │ 账号 / 会话归属 / 策略 / 审计
                              ▼ HTTP/WS 代理
                            DSH Web 上游 :3080（127.0.0.1，仅回环）
```

- **DSH 永远只绑 127.0.0.1**（绑通配地址会被它自己拒绝，这是上游的安全设计）。
- **所有局域网访问都走网关 3090**：网关把"一个 token 身份"拆成 N 个账号，共享 =
  "读工作区文件 + 看会话历史 + 排队发纯文本"，仅此而已。

## 2. 环境要求

- Windows 10/11，Node.js ≥ 22（本机实测 v24.22.1）
- PowerShell 任意版本都行（本机是 5.1，脚本已按它调过）
- **不需要装任何全局包**。DSH 安装在 `alt\node_modules\` 里，网关依赖在 `probe\hub-fix\` 里
- 若把整个文件夹拷到别的电脑：只要 Node 在，`probe\hub-fix` 首次运行缺 `ws` 时执行
  `npm install --prefix .\probe\hub-fix ws@^8.18.0`

## 3. 三步跑起来

**开两个独立终端窗口**（各自执行，`Ctrl+C` 或关窗口即停止该进程）：

```powershell
# 终端 1 —— DSH 上游（3080）
cd C:\Users\37842\Desktop\dsh联机
cmd /c "probe\start-dsh.cmd"

# 终端 2 —— 网关（3090）  ⚠ 必须等终端 1 出现 LISTENING 之后再启动！
cd C:\Users\37842\Desktop\dsh联机
cmd /c "probe\start-gateway.cmd"
```

> **顺序不能反**：网关启动时会做一次会话/工作区归属同步；如果 DSH 还没就绪，网关拿到
> 空表就会把已有工作区当成新的重建（工作区 id 轮换，旧 id 永久失效，报告 §6.11），
> 新会话也会踩上 5 分钟归属滞后（发现 A）。判断方法：终端 1 里出现
> `dsh web: http://127.0.0.1:3080/?token=…`，且下面 netstat 能看到 3080 那一行，再开终端 2。

**确认都起来了**（在第三个终端）：

```powershell
netstat -ano | Select-String "LISTENING" | Select-String ":3080|:3090"
```

必须看到两行，且网关那行是 `0.0.0.0:3090`：

```
TCP    127.0.0.1:3080    0.0.0.0:0    LISTENING    <pid>
TCP    0.0.0.0:3090      0.0.0.0:0    LISTENING    <pid>
```

**一键自检**（两个进程都在跑的前提下，14 条断言，约 2 秒）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File demo\rehearse.ps1
```

末行看到 `REHEARSAL: all checks PASS` 即为健康。留档在 `probe\p7-rehearsal.txt`。

浏览器入口：

| 地址 | 说明 |
|---|---|
| `http://127.0.0.1:3090/login` | 登录页 |
| `http://127.0.0.1:3090/` | 登录后即完整 DSH 界面 |
| `http://127.0.0.1:3090/admin/` | 管理控制台（仅 admin；alice/bob 访问得 403） |

> 新建账号首次登录会 302 到 `/change-password`，改密字段名是 **`current` / `next`**
> （完整流程见演示文档 §4.3）。

## 5. 演示当天怎么走

照《课堂演示操作流程.docx》执行即可，要点：

1. **上台前**：§1.2 前置条件清单逐条打勾（两个端口、token 可读、三账号可登录、
   payload 齐全、`alice-notes.txt` 靶子存在）。
2. **必须先重启网关**：新建会话有最长 5 分钟的归属滞后（发现 A）。重启立即填表，
   否则 alice 会报"无权访问该会话或工作区"，而 bob 自己能进——最冤枉的现场事故。
3. **分镜 6（权限边界，300 秒）是打分重心**，命令全在文档 §5.2，每条一行、输出一句。
4. 若换了会话 id，重建 payload：`node demo\make-payloads.mjs <新sessionId>`（文档 §4.8）。
5. 彩排已于 2026-11-19 在按序重启的全新进程上复跑：`demo\rehearse.ps1` **14/14 全 PASS**，
   留档 `probe\p7-rehearsal.txt`。启动顺序、动态 id 解析这两条纪律对全新环境同样成立。

## 6. 常用操作速查

```powershell
# 看审计日志（中文必须 -Encoding UTF8）
Get-Content hubhome\logs\audit.jsonl -Encoding UTF8 -Tail 20

# 或经 API 拉（admin 会话）
curl.exe -s -b demo\admin.jar "http://127.0.0.1:3090/__teamhub/api/audit?limit=20"

# 重跑 8 个权限边界用例（脚本自己登录，两个进程在跑即可）
node probe\p5-boundary.mjs

# 复现四个"文档没写"的发现
node probe\p5-upstream-nofence.mjs        # 发现 B：绕过网关直连 3080 无路径围栏
node probe\p5-ws-revoke.mjs               # 发现 C：撤权后 WS 不关闭
node probe\p5-lag-live.mjs <sessionId>    # 发现 A：归属滞后（约 4–5 分钟，耐心等）
node probe\p8-crash.mjs                   # 发现 D：畸形 JSON（已打补丁 C，网关应存活）
```

**重置网关数据**（清空账号重来；先停掉网关进程）：

```powershell
Remove-Item -Recurse -Force hubhome
$env:DSH_TEAM_HUB_HOME="$PWD\hubhome"
node .\probe\hub-fix\bin\dsh-team-hub.js init alice bob   # admin 初始密码只显示一次，当场记下！
cmd /c "probe\start-gateway.cmd"
```

**停止**：两个终端各按 `Ctrl+C`；确认 `netstat` 里 3080/3090 消失。

## 7. 十一个坑（每条都真实踩过）

| # | 症状 | 原因 → 修法 |
|---|---|---|
| 1 | 审计每 3 秒刷 `token unavailable`，自检全红 | 四个成因见演示文档 §6 前 4 行；最常见是 PS 5.1 `Tee-Object` 写成 UTF-16LE → **一律用 `probe\start-dsh.cmd`** |
| 2 | 成员 RPC 返回 `ERR: request failed` | 上游错误被网关统一改写；先查 `range`（必填，offset 从 1 起）与 `sessionId` 形状 |
| 3 | 成员界面大面积功能缺失、控制台一堆 403 | 用了未打补丁的网关 → 只用 `probe\hub-fix` |
| 4 | 共享配好了，成员进不去会话 | 发现 A 的 5 分钟滞后 → 重启网关 |
| 5 | `Cannot find package 'ws'` | `npm install --prefix .\probe\hub-fix ws@^8.18.0` |
| 6 | `SyntaxError: Unexpected token '﻿'` | profile 的 package.json 带 BOM → 用 `[System.IO.File]::WriteAllText($p,$t,(New-Object System.Text.UTF8Encoding($false)))` |
| 7 | 一条 curl 后网关整个消失 | 畸形 JSON 崩进程（发现 D）；已打补丁 C，但仍**一律 `--data-binary "@文件"`**，别内联 JSON |
| 8 | `{"error":"token query not accepted"}` | URL 上带了 `?token=` → 去掉 |
| 9 | audit 中文乱码 `鎴愬憳…` | `Get-Content` 默认 ANSI → 加 `-Encoding UTF8` |
| 10 | `.ps1` 里中文路径变 `dsh鑱旀満` | 脚本文件无 BOM 被 ANSI 解码 → 存 UTF-8 带 BOM。**与第 6 条相反**：package.json 不能带 BOM，.ps1 要带 |
| 11 | `{"error":"上游工作区已变更，请刷新后重试"}`（409） | 工作区 id 已轮换（网关在 DSH 就绪前启动过）→ 按 §3 顺序重启两进程，再 `node demo\make-payloads.mjs` 重建 payload；`rehearse.ps1` 与演示文档已改为动态解析 id，一般不用手动改 |

另有一条纪律：**共享请求体必须恰好是 `{"members":["alice"]}`**，多一个键都 400。
