# Introduction-to-AI-homework

欢迎来到 人工智能导论课程作业提交仓库！本仓库采用**网页端直接提交**的方式。请所有同学严格按照以下规范提交作业。

## 📌 提交规范

1. **接受协作者邀请**：课代表在后台将大家添加为协作者（Collaborator）。请前往注册 GitHub 的邮箱查收邀请邮件并点击接受，或直接打开本仓库主页点击顶部的Accept invitation 按钮。
2. **直接上传**：无需 Fork，无需创建分支，无需发起 PR。所有操作直接在本仓库的网页端完成，直接上传。
3. **建立专属目录**：请在 students/你的学号/ 目录下完成作业。例如students/63026***/hw1。每次作业必须单独建立一个文件夹（如 hw1, hw2）。
4. **只允许修改自己的目录**：只能修改 students/本人学号/ 目录，**严禁修改或删除其他同学的目录，严禁修改 README.md 等公共文件！**
## 📂 目录结构

```text
├── README.md                  # 提交说明（本文件）
├── students/                  # 学生提交目录
│   ├── 63026101/             # 示例：你的学号目录
│   │   ├── hw1/               # 第一次作业文件夹（包含代码、报告、截图等）
│   │   └── hw2/               # 第二次作业文件夹
│   └── 63026102/             # 其他同学的目录
