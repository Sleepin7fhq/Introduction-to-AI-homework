# Introduction-to-AI-homework

欢迎来到 人工智能导论课程作业提交仓库！本仓库采用**网页端直接提交**的方式。请所有同学严格按照以下规范提交作业。

## 📌 提交规范

1. **接受协作者邀请**：课代表在后台将大家添加为协作者（Collaborator）。请前往注册 GitHub 的邮箱查收邀请邮件并点击接受，或直接打开本仓库主页点击顶部的Accept invitation 按钮。
2. **直接上传**：无需 Fork，无需创建分支，无需发起 PR。所有操作直接在本仓库的网页端完成，直接上传。
3. **建立专属目录**：请在 homework/hwn/你的学号和姓名/ 下完成作业。例如homework/hw1/63026001张三/。每次作业必须在hwn下单独建立一个文件夹hw1/63026001张三，hw2/63026001张三。
4. **建新文件夹方法**：由于GitHub不能创建空文件夹，请在新建文件时，打开对应作业的文件夹homework/hwn，点击右上角add file，选择create new file，然后在上方文件名框输入 你的学号姓名/占位文件，如 /63026001张三/README.md 。否则无法正常创建新文件夹。每次文件夹添加需要保存（或文件上传）时，点击右上角绿色的commit changes。
5. **只允许修改自己的目录**：只能修改 homework/hw1/本人学号和姓名 的目录，**严禁修改或删除其他同学的目录，严禁修改 README.md 等公共文件！**
