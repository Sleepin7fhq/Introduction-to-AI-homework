## 1. 读题与求解

```
这是一道高等数学的极限题，题目如下（附图）：

    lim_{x→0} [(1+mx)^n − (1+nx)^m] / x²,  m, n ∈ ℕ₊

要求：
1. 先复述题意，确认没有看错；
2. 给出完整的推导，每一步说明依据（用了哪个定理/公式）；
3. 结论要能通过特殊值检验，请至少验证 m=n、m=1,n=2、m=2,n=1 三种情形；
4. 不确定的地方明说，不要编造。
```

**结果**：得到 $L=mn(n-m)/2$，并确认了 m=n 时为 0、m=1,n=2 时为 1、m=2,n=1 时为 −1。

---

## 2. 多解法互证

```
上面的推导用二项式展开。请再给两种不同的做法：
1. 用二阶导数（说明为什么分母是 x² 而不是 x 或 x³）；
2. 用洛必达法则（注意要几次，条件是什么）。

最后指出三种方法共同的本质。
```

**结果**：导数法给出 $L=f''(0)/2$；洛必达法需两次；三者本质都是"提取 x² 的系数"。

---

## 3. 代码验证

```
写一个可以直接运行的 Node.js 脚本（不要依赖任何第三方库），做三件事：
1. 用 m,n 的公式算出精确值；
2. 用最朴素的直接代值法，在 x = 1e-2、1e-4、1e-6、1e-8 下求数值，列表对照；
3. 观察并解释：为什么 x 小到一定程度后，数值结果反而变差。

最后把结论写清楚：这是数值的问题，还是数学的问题。
```

**结果**：`generate.mjs` 的第 1 段代码。x=1e-8 时 (3,5) 算出 19.98（真值 15），相对误差 33%——
典型的灾难性抵消（两个几乎相等的浮点数相减）。这反而成了"为什么需要解析推导"的最好论据。

## 6. 一句话总结

> 这道题的难点不在计算，而在于**发现两个括号的一次项恰好相同**。
> 看清这一点，剩下的只是把与 x² 同阶的项写全；
> 而数值实验的作用是**体检**，不是证明——它在 1e-8 处失效，恰恰证明了这一点。
