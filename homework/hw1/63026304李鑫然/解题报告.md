# 2025 年全国一卷数学第 19 题

本报告已核对该转载图。以下按数学条件重新整理题目，不附整张试卷。
转载图第一问写为闭区间 [0, π/4]，部分文字整理版本写作开区间 (0, π/4)。
两种版本均包含内点 π/6，因此本题最大值及取到最大值的点不受影响。

设 f(x)=5cos x−cos 5x。

1. 求 f 在 [0,π/4] 上的最大值。
2. 给定 0<θ<π，a∈R，证明存在 y∈[a−θ,a+θ]，使 cos y≤cos θ。
3. 设 b∈R。若存在相位 φ∈R，使 5cos x−cos(5x+φ)≤b 对所有 x∈R 成立，求 b 的最小值。

## 第一问：导数与单调性

对 f 求导，利用正弦差化积：

f′(x)=−5sin x+5sin 5x
     =10cos 3x·sin 2x。

在 0<x<π/4 内，sin 2x>0。因此导数的符号由 cos 3x 决定。

- 当 0<x<π/6 时，cos 3x>0，函数递增。
- 当 π/6<x<π/4 时，cos 3x<0，函数递减。

所以最大值在 x=π/6 取得：

f(π/6)=5cos(π/6)−cos(5π/6)
      =5√3/2+√3/2
      =3√3。

答案：最大值为 3√3，约为 5.196152423。

## 第二问：构造满足条件的点

利用余弦函数的周期性，取整数 k，使

α=a−2kπ∈[−π,π]。

分三种情况：

1. 若 |α|≥θ，取 y=a。此时 y 自然在要求的区间内，
   且 cos y=cos|α|≤cos θ，因为 cos 在 [0,π] 上递减。
2. 若 0≤α<θ，取 y=2kπ+θ。此时 |y−a|=θ−α≤θ，
   因而 y∈[a−θ,a+θ]，并且 cos y=cos θ。
3. 若 −θ<α<0，取 y=2kπ−θ。此时 |y−a|=θ+α<θ，
   因而 y∈[a−θ,a+θ]，并且 cos y=cos θ。

以上情况覆盖全部实数 a，因此结论成立。

## 第三问：先证明下界，再构造达到下界的相位

令 Gφ(x)=5cos x−cos(5x+φ)。
题目等价于求 minφ maxx Gφ(x)。
量词顺序是“存在一个固定的 φ，对所有 x 都成立”。
不能让 φ 随 x 改变。

### 任意相位都需要 b≥3√3

任取 φ∈R。在第二问中取 a=φ，θ=5π/6。
可得某个 y 满足

y∈[φ−5π/6,φ+5π/6]，
cos y≤cos(5π/6)=−√3/2。

令 x=(y−φ)/5，则 x∈[−π/6,π/6]。
因此 cos x≥√3/2，而 5x+φ=y。

于是

Gφ(x)=5cos x−cos y
     ≥5√3/2+√3/2
     =3√3。

这说明无论如何选 φ，总能找到一个 x 使 Gφ(x)≥3√3。
因此，任何满足题意的 b 都必须满足 b≥3√3。

### 取 φ=0 时，全体实数上的上界就是 3√3

不能只引用第一问，因为第一问仅讨论一个短区间。
下面另证全局上界。

令 c=cos x∈[−1,1]，利用五倍角公式：

cos 5x=16c⁵−20c³+5c。

从而

G₀(x)=−16c⁵+20c³=h(c)。

h′(c)=−80c⁴+60c²=20c²(3−4c²)。

在闭区间 [−1,1] 上检查端点和全部驻点：

| c | h(c) |
|---|---|
| −1 | −4 |
| −√3/2 | −3√3 |
| 0 | 0 |
| √3/2 | 3√3 |
| 1 | 4 |

因此 max h(c)=3√3。
取 φ=0，可以让 G₀(x)≤3√3 对所有实数 x 成立。

结合必要下界与可实现的上界，得到：

**b 的最小值为 3√3，φ=0 是一种达到最优值的选择。**

## 代码验证的方法

附件 verify.py 仅使用 Python 标准库，可独立运行。

1. 在第一问区间取 2401 个网格点，核验最大值和取值位置。
2. 用固定随机种子 202519，检查第二问的 5000 个随机案例与 75 个边界案例。
3. 在 [0,2π] 上扫描 721 个相位。固定相位下枚举全部驻点，
   而不是只用稀疏的 x 网格估计峰值。
4. 对各相位构造第三问所需的见证点，检查函数值不小于 3√3。
5. 用 25 个相位、每个相位 12001 个 x 网格点，独立交叉核验驻点法。
6. 检查五倍角多项式与原三角函数表达式一致。

驻点公式来自：

sin(5x+φ)=sin x

等价于

x=kπ/2−φ/4，
或 x=(2k+1)π/6−φ/6，k∈Z。

程序在一个完整周期内检查这些驻点和端点，从中求最大值。
verification.json 保存实际运行结果，chart_data.json 保存 PPT 图表使用的数据。

有限数值检查不构成对全部实数的证明。
本题结论的严格性由前面的导数分析、构造性证明和上下界证明保证。
