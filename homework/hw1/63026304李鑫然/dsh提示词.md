## 提示词 1：独立解题

请解答 2025 年全国一卷数学第 19 题，并给出严格、适合课堂展示的证明。
题目条件如下：

设 f(x)=5cos x−cos 5x。
（1）求 f 在 [0,π/4] 上的最大值。
（2）给定 θ∈(0,π)、a∈R，证明存在 y∈[a−θ,a+θ]，使 cos y≤cos θ。
（3）若存在固定的 φ∈R，使 5cos x−cos(5x+φ)≤b 对任意 x∈R 成立，
求 b 的最小值。

要求：
1. 写清各小问的思路、推导和结果。
2. 第三问分别证明任意相位下的必要下界，以及某个相位能够达到这个上界。
3. 第一问的区间结论不能直接当成第三问全体实数上的结论。
4. 注意“存在 φ，对所有 x”这一量词顺序。
5. 数值图像和采样仅用于辅助，不能代替证明。
6. 若发现题目版本的区间端点不同，请说明是否影响结果。

## 提示词 2：审查与补全证明

请逐步检查刚才的证明，重点检查：

1. f′(x) 的正弦差化积系数是否正确。
2. 第二问是否覆盖所有实数 a、区间端点和 α=0。
3. 第三问能否令第二问中的 a=φ、θ=5π/6，
   并取 x=(y−φ)/5，推出 Gφ(x)≥3√3。
4. φ=0 时，是否已证明对所有实数 x 都有 G₀(x)≤3√3。
5. 请列出推导中最容易出现的错误，并逐项确认是否存在。

## 提示词 3：编写并执行核验代码

请用 Python 标准库编写可独立运行的核验脚本，并实际执行。
若环境不允许执行，请明确说明，不要编造输出。

检查内容：
1. 第一问取 2401 个网格点。
2. 对第二问给出见证点的构造算法，固定随机种子为 202519，
   检查 5000 个随机案例，并额外检查端点与周期边界。
3. 对 φ∈[0,2π] 扫描 721 个相位。
   固定 φ 时，利用
   x=kπ/2−φ/4 和 x=(2k+1)π/6−φ/6
   两族驻点，求一个周期内的最大值。
4. 额外用稠密 x 网格交叉检查，防止漏掉驻点。
5. 输出计算结果和检查数量，保存为 JSON 文件。
6. 说明有限采样与严格证明的区别。
