【题目】
2026 年普通高等学校招生全国统一考试（新课标 II 卷）· 数学 · 第 17 题
（解答题，满分 15 分）

在 △ABC 中，已知 cos B = 3/4，cos²(A+C) + sin A·sin C = 1。

(1) 证明：△ABC 为钝角三角形；
(2) 若 △ABC 的面积为 √7/4，求 △ABC 的周长。

----------------------------------------------------------------
【来源】

【参考答案（官方）】
钝角三角形；周长 3 + √2。

----------------------------------------------------------------
【完整解答】

■ 第 (1) 问

  ∵ A + B + C = π  ∴ A + C = π − B
  ∴ cos(A+C) = cos(π−B) = −cos B = −3/4                        …… ①

  由 cos²(A+C) + sin A·sin C = 1：
      sin A·sin C = 1 − 9/16 = 7/16                             …… ②

  由和角公式 cos(A+C) = cos A·cos C − sin A·sin C：
      cos A·cos C = cos(A+C) + sin A·sin C
                  = −3/4 + 7/16 = −12/16 + 7/16 = −5/16        …… ③

  ∵ ③ 中 cos A·cos C < 0，且 A、C ∈ (0, π)，
  ∴ cos A 与 cos C 异号 ⇒ A、C 中恰有一个为钝角；
  又 cos B = 3/4 > 0 ⇒ B 为锐角。
  ∴ △ABC 为钝角三角形。                                        ∎

  （补充：由 cos(A−C) = cos A·cos C + sin A·sin C = 1/8，
    可还原 A+C ≈ 138.59°、|A−C| ≈ 82.82°，
    得 A ≈ 110.70°、C ≈ 27.89°、B ≈ 41.41°，和为 180°。
    即钝角是 A（A、C 可互换），而不只是“某个角”。）

■ 第 (2) 问

  ① 求 sin B：
     cos B = 3/4，B ∈ (0, π) ⇒ sin B = √(1 − 9/16) = √7/4

  ② 由面积求 ac：
     S = (1/2)·a·c·sin B
     √7/4 = (1/2)·a·c·(√7/4)  ⇒  a·c = 2

  ③ 正弦定理（a = 2R sin A，c = 2R sin C）：
     ac = 4R²·sin A·sin C = 4R²·(7/16) = 7R²/4
     7R²/4 = 2  ⇒  R² = 8/7

  ④ 再求 b：
     b = 2R·sin B = 2·√(8/7)·(√7/4) = √8/2 = √2

  ⑤ 余弦定理：
     b² = a² + c² − 2ac·cos B
     2  = a² + c² − 2·2·(3/4) = a² + c² − 3
     ⇒ a² + c² = 5

  ⑥ 配方求 a + c：
     (a+c)² = a² + c² + 2ac = 5 + 4 = 9
     a + c = 3   （边长为正，取正号）

  ⑦ 周长：
     a + b + c = (a + c) + b = 3 + √2  ≈ 4.4142

  ∴ △ABC 的周长为 3 + √2。                                     ∎

【验算】
  三边为 {a, c} = {1, 2}，b = √2（三者由 ac = 2、a+c = 3 解 t²−3t+2=0 得到）。
  ① 三角不等式：1 + √2 ≈ 2.414 > 2 ✓
  ② cos B = (2² + 1² − 2)/(2·2·1) = 3/4 ✓
  ③ cos A = (2 + 1 − 4)/(2·√2) = −0.3536 < 0 ⇒ A 为钝角 ✓
  ④ 面积 = (1/2)·2·1·√7/4 = √7/4 ✓
  ⑤ 周长 = 1 + √2 + 2 = 3 + √2 ✓
