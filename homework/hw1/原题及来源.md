# 原题及来源

## 一、题目原文

**2022 年普通高等学校招生全国统一考试（甲卷）· 理科数学 · 第 21 题（12 分）**

> 已知函数 $f(x)=\dfrac{e^{x}}{x}-\ln x+x-a$。
>
> （1）若 $f(x)\geqslant 0$，求 $a$ 的取值范围；
>
> （2）证明：若 $f(x)$ 有两个零点 $x_1$，$x_2$，则 $x_1x_2<1$。

题面中隐含定义域：$\ln x$ 与 $\dfrac{e^x}{x}$ 都要求 $x>0$，因此全部讨论都在正半轴 $(0,+\infty)$ 上进行。

## 四、选题理由

1. **思维性强**：第（2）问不能直接套用单调性，必须先做一步"双零点 ⇒ 单变量不等式"的化归；
2. **结构清晰**：两问层层递进，第（1）问的极值结论是第（2）问的前提（$a>e+1$ 才可能有两个零点）；
3. **答案唯一且可核**：临界值为 $e+1$，结论为严格不等式 $x_1x_2<1$，都可用高精度数值独立验证；
4. **有方法论价值**：属于"极值点偏移"典型题型，解法可迁移到同类导数压轴题。

```text

纯文本:          f(x) = e^x/x - ln x + x - a   (x > 0)
Python:         def f(x, a): return math.exp(x)/x - math.log(x) + x - a
```
