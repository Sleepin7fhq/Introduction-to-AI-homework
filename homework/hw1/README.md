## 一句话简介

从高考真题库中选取 **2022 年高考全国甲卷·理科数学第 21 题**（导数压轴题，属"极值点偏移"典型题型），
独立给出两问的完整证明，并用 60 位十进制精度的数值实验对每一步结论做独立复核。

## 题目速览

设 $f(x)=\dfrac{e^{x}}{x}-\ln x+x-a\ (x>0)$。

1. 若 $f(x)\geqslant 0$ 恒成立，求 $a$ 的取值范围；
2. 证明：若 $f(x)$ 有两个零点 $x_1,x_2$，则 $x_1x_2<1$。

## 结论

| 问 | 答案 |
|---|---|
| （1） | $a\leqslant e+1$，即 $a\in(-\infty,\ e+1]$ |
| （2） | $x_1x_2<1$（构造 $h(x)=f(x)-f(1/x)$，两次求导判定符号后得证） |

核心思路：$f(x)=g(x)-a$ 中 $a$ 只是竖直平移，因此单调性、极值点与 $a$ 无关；
再用"双零点问题 ⇒ 单变量函数不等式 $f(x)<f(1/x)$"这一步化归，把两个未知零点的不等式
变成关于一个自由变量的命题。

## 方法要点（可迁移）

**极值点偏移**类问题的通用套路：

1. 用导数锁定极值点与两侧的严格单调区间；
2. 把双零点关系转化为单变量比较（与 $f(1/x)$，或与 $f(2x_0-x)$ 比较）；
3. 构造差函数（本题为 $h(x)=f(x)-f(1/x)$），用两次求导判定符号；
4. 利用端点值（本题 $h(1)=0$）给出符号基准，配合严格单调完成结论。

# 原题及来源

## 一、题目原文

**2022 年普通高等学校招生全国统一考试（甲卷）· 理科数学 · 第 21 题（12 分）**

> 已知函数 $f(x)=\dfrac{e^{x}}{x}-\ln x+x-a$。
>
> （1）若 $f(x)\geqslant 0$，求 $a$ 的取值范围；
>
> （2）证明：若 $f(x)$ 有两个零点 $x_1$，$x_2$，则 $x_1x_2<1$。

题面中隐含定义域：$\ln x$ 与 $\dfrac{e^x}{x}$ 都要求 $x>0$，因此全部讨论都在正半轴 $(0,+\infty)$ 上进行。

## 四、选题理由

1. **思维性强**：第（2）问不能直接套用单调性，必须先做一步"双零点 ⇒ 单变量不等式"的化归；
2. **结构清晰**：两问层层递进，第（1）问的极值结论是第（2）问的前提（$a>e+1$ 才可能有两个零点）；
3. **答案唯一且可核**：临界值为 $e+1$，结论为严格不等式 $x_1x_2<1$，都可用高精度数值独立验证；
4. **有方法论价值**：属于"极值点偏移"典型题型，解法可迁移到同类导数压轴题。

## 五、公式在不同环境下的写法

```text
Markdown/LaTeX:  f(x)=\frac{e^{x}}{x}-\ln x+x-a \quad (x>0)
纯文本:          f(x) = e^x/x - ln x + x - a   (x > 0)
Python:         def f(x, a): return math.exp(x)/x - math.log(x) + x - a
```

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
对 2022 年高考全国甲卷·理科数学第 21 题解答的独立数值/符号检验。

题目: f(x) = e^x/x - ln x + x - a  (x>0)
 (1) 若 f(x) >= 0 恒成立, 求 a 的取值范围;
 (2) 若 f(x) 有两个零点 x1 < x2, 证明 x1*x2 < 1.

本脚本只做"检验", 不参与推导: 它用 60 位十进制精度独立重算
导数、单调性、极值、零点以及待证不等式。
"""
from decimal import Decimal, getcontext

getcontext().prec = 60

D = Decimal
E = D(1).exp()          # 自然常数 e, 60 位精度


def g(x):
    """g(x) = e^x/x - ln x + x,   f(x) = g(x) - a"""
    x = D(x)
    return x.exp() / x - x.ln() + x


def gp(x):
    """g'(x) = (e^x + x)(x-1)/x^2  (推导结果, 用有限差分独立复核)"""
    x = D(x)
    return (x.exp() + x) * (x - 1) / (x * x)


def f(x, a):
    return g(x) - D(a)


def h(x):
    """h(x) = f(x) - f(1/x) = g(x) - g(1/x)  (与 a 无关)"""
    x = D(x)
    return g(x) - g(1 / x)


def hp_formula(x):
    """解答中推出的 h'(x) = (x-1)/x^2 * [e^x + x - x*e^(1/x) - 1]"""
    x = D(x)
    m = x.exp() + x - x * (1 / x).exp() - 1
    return (x - 1) / (x * x) * m


def hp_fd(x, eps="1e-25"):
    """用中心差分独立计算 h'(x)"""
    x = D(x)
    e = D(eps)
    return (h(x + e) - h(x - e)) / (2 * e)


def m(x):
    """m(x) = e^x + x - x*e^(1/x) - 1"""
    x = D(x)
    return x.exp() + x - x * (1 / x).exp() - 1


def mp(x):
    """m'(x) = e^x + 1 + e^(1/x)*(1/x - 1)  (推导结果)"""
    x = D(x)
    return x.exp() + 1 + (1 / x).exp() * (1 / x - 1)


def bisect(func, lo, hi, iters=400):
    """在 [lo,hi] 上二分求根, 要求 func(lo) 与 func(hi) 异号"""
    flo = func(lo)
    for _ in range(iters):
        mid = (lo + hi) / 2
        fm = func(mid)
        if (fm < 0) == (flo < 0):
            lo, flo = mid, fm
        else:
            hi = mid
    return (lo + hi) / 2


def find_root_left(a):
    """f(1)<0, f(x)->+inf (x->0+), 先向左扩张区间再二分"""
    lo = D(1) / 2
    while f(lo, a) < 0:
        lo /= 2
    return bisect(lambda x: f(x, a), lo, D(1))


def find_root_right(a):
    """f(1)<0, f(x)->+inf (x->+inf), 先向右扩张区间再二分"""
    hi = D(2)
    while f(hi, a) < 0:
        hi = 1 + (hi - 1) * 2
        assert hi < D("1000"), "扩张区间越界"
    return bisect(lambda x: f(x, a), D(1), hi)


def ok(cond):
    return "PASS" if cond else "**FAIL**"


print("=" * 78)
print("检验 0: 常数与极值")
print("=" * 78)
print(f"e                    = {E}")
print(f"g(1) = e + 1         = {g(1)}")
print(f"e + 1 (直接计算)      = {E + 1}")
print(f"两者相等? {ok(abs(g(1) - (E + 1)) < D('1e-55'))}")
print(f"g'(1)                = {gp(1)}   (应为 0: {ok(abs(gp(1)) < D('1e-55'))})")
gmin = min(g(D(1) + D(k) / 1000) for k in range(-50, 51))
print(f"x=1 邻域扫描最小值     = {gmin}  (>= g(1): {ok(gmin >= g(1))})")

print()
print("=" * 78)
print("检验 1: g'(x) 公式正确性 (解析式 vs 中心差分)")
print("=" * 78)
worst = D(0)
for t in [D("0.05"), D("0.3"), D("0.7"), D("0.99"), D("1.01"), D("1.5"), D("3"), D("10")]:
    fd = (g(t + D("1e-25")) - g(t - D("1e-25"))) / (2 * D("1e-25"))
    rel = abs(fd - gp(t)) / max(abs(fd), D("1e-40"))
    worst = max(worst, rel)
print(f"8 个采样点上 (g'(x)_差分 - g'(x)_解析)/|.| 的最大值 = {worst:.3E}")
print(f"解析导数公式与数值差分一致 (<1e-20)? {ok(worst < D('1e-20'))}")
print(f"g' 在 (0,1) 上 <0 ? {ok(all(gp(D(k)/200) < 0 for k in range(1, 200)))}")
print(f"g' 在 (1,inf) 上 >0 ? {ok(all(gp(1 + D(k)/50) > 0 for k in range(1, 500)))}")

print()
print("=" * 78)
print("检验 2: h(x)=g(x)-g(1/x) 在 (0,1) 上恒为负 (第(2)问核心引理)")
print("=" * 78)
vals = [D(k) / 1000 for k in range(1, 1000)]
hs = [h(x) for x in vals]
print(f"x 从 0.001 到 0.999 扫描 999 点:  max h(x) = {max(hs)}")
print(f"h(x) < 0 全部成立? {ok(all(v < 0 for v in hs))}")
print(f"h(1) = {h(1)}  (应为 0: {ok(h(1) == 0)})")
worst_h = max(abs(hp_fd(x) - hp_formula(x)) for x in [D("0.1"), D("0.4"), D("0.8"), D("0.95")])
print(f"h'(x) 解析式 vs 差分 最大相对偏差 = {worst_h:.3E}")
print(f"h'(x) > 0 在 (0,1) 上成立? {ok(all(hp_formula(D(k)/1000) > 0 for k in range(1, 1000)))}")

print()
print("=" * 78)
print("检验 3: 辅助函数 m(x)=e^x+x-xe^(1/x)-1 的符号与单调性")
print("=" * 78)
print(f"m(1) = {m(1)}  (应为 0: {ok(abs(m(1)) < D('1e-55'))})")
print(f"m(x)<0 且 m'(x)>0 在 (0,1) 上? "
      f"{ok(all(m(D(k)/1000) < 0 and mp(D(k)/1000) > 0 for k in range(1, 1000)))}")
print(f"m'(x) 最小值 (0<x<1) = {min(mp(D(k)/1000) for k in range(1, 1000))}")
# 用差分复核 m'(x)
w = max(abs((m(x + D('1e-25')) - m(x - D('1e-25'))) / (2 * D('1e-25')) - mp(x))
        for x in [D("0.2"), D("0.5"), D("0.9")])
print(f"m'(x) 解析式 vs 差分 最大偏差 = {w:.3E}   {ok(w < D('1e-20'))}")

print()
print("=" * 78)
print("检验 4: 第一问 —— a 的临界值 (数值求 g 的最小值)")
print("=" * 78)
# 用三分搜索独立求 g 在 (0, 20] 上的最小值
lo, hi = D("0.01"), D("20")
for _ in range(300):
    m1 = lo + (hi - lo) / 3
    m2 = hi - (hi - lo) / 3
    if g(m1) < g(m2):
        hi = m2
    else:

# 解答

> 题目：2022 年高考全国甲卷·理科数学第 21 题（详见 `原题及来源.md`）
>
> 设 $f(x)=\dfrac{e^{x}}{x}-\ln x+x-a\ (x>0)$。
> （1）若 $f(x)\geqslant 0$，求 $a$ 的取值范围；（2）证明：若 $f(x)$ 有两个零点 $x_1,x_2$，则 $x_1x_2<1$。

---

## 一、审题与整体思路

1. **定义域**：$x>0$。
2. **关键观察**：记 $g(x)=\dfrac{e^{x}}{x}-\ln x+x$，则 $f(x)=g(x)-a$。
   于是 $a$ 只是一个**上下平移量**——$f$ 的单调性、极值点位置、零点的"分布结构"都与 $a$ 无关，
   只有零点的具体位置随 $a$ 变。整道题的骨架就建立在这个观察上。
3. **两问的关系**：第（1）问给出 $g$ 的最小值 $e+1$，从而第（2）问的"两个零点"暗含 $a>e+1$，
   并保证零点分居 $1$ 的两侧。

---

## 二、第（1）问：求 $a$ 的取值范围

对 $x>0$ 求导：

$$
f'(x)=\Bigl(\frac{e^{x}}{x}\Bigr)'-\frac1x+1
=\frac{e^{x}(x-1)}{x^{2}}-\frac1x+1 .
$$

后两项通分：$-\dfrac1x+1=\dfrac{x-1}{x}$，于是

$$
f'(x)=\frac{(x-1)e^{x}}{x^{2}}+\frac{x-1}{x}
=(x-1)\Bigl(\frac{e^{x}}{x^{2}}+\frac1x\Bigr)
=\frac{(x-1)\bigl(e^{x}+x\bigr)}{x^{2}} .
$$

由于 $x>0$ 时 $x^{2}>0$、$e^{x}>0$、$x>0$，故 $e^{x}+x>0$，$f'(x)$ 的符号完全由 $x-1$ 决定：

- $0<x<1$ 时 $f'(x)<0$，$f$ 在 $(0,1)$ 上**严格递减**；
- $x>1$ 时 $f'(x)>0$，$f$ 在 $(1,+\infty)$ 上**严格递增**。

故 $f$ 在 $x=1$ 处取到全局最小值

$$
f(1)=\frac{e^{1}}{1}-\ln 1+1-a=e+1-a .
$$

"$f(x)\geqslant 0$ 对一切 $x>0$ 成立"$\iff$"最小值 $\geqslant 0$"，即

$$
\boxed{\,a\leqslant e+1\,}\qquad\text{即}\quad a\in(-\infty,\ e+1].
$$

顺带得到第（2）问的前提：$f$ 要有两个零点，必须 $f(1)=e+1-a<0$，即 $a>e+1$。

---

## 三、第（2）问：证明 $x_1x_2<1$

### 3.1 两个零点分居 1 的两侧

设 $a>e+1$。此时 $f(1)=e+1-a<0$；又

- $x\to 0^{+}$ 时 $\dfrac{e^{x}}{x}\to+\infty$ 且 $-\ln x\to+\infty$，故 $f(x)\to+\infty$；
- $x\to+\infty$ 时 $g(x)=\dfrac{e^{x}}{x}-\ln x+x\to+\infty$，故 $f(x)\to+\infty$。

由 $f$ 在 $(0,1)$ 严格递减、在 $(1,+\infty)$ 严格递增，结合介值定理：在 $(0,1)$ 内有唯一零点 $x_1$，
在 $(1,+\infty)$ 内有唯一零点 $x_2$，即

$$
0<x_{1}<1<x_{2},\qquad f(x_1)=f(x_2)=0 .
$$

### 3.2 把双零点问题化归为单变量不等式

要证 $x_{1}x_{2}<1$，只需证

$$
x_{2}<\frac1{x_{1}} .
$$

注意 $\dfrac1{x_1}>1$，与 $x_2$ 同落在 $f$ 的**严格递增区间** $(1,+\infty)$ 上；
$f$ 严格递增意味着

$$
f(x_2)<f\!\Bigl(\frac1{x_1}\Bigr)\iff x_2<\frac1{x_1}.
$$

而 $f(x_2)=f(x_1)$，于是原题等价于下面这个只含一个自由变量的命题：

$$
\boxed{\ \text{对任意 }0<x<1,\ \ f(x)<f\!\Bigl(\frac1x\Bigr).\ }
$$

这是全题最关键的一步"转弯"：把"两个未知零点"的不等式，换成"一个自由变量"的函数不等式。

### 3.3 核心引理：$0<x<1$ 时 $f(x)<f(1/x)$

构造差函数（$a$ 会自动消去）

$$
h(x)=f(x)-f\!\Bigl(\frac1x\Bigr),\qquad 0<x<1 .
$$

**第一步，求导。** 由复合函数求导，

$$
h'(x)=f'(x)+\frac{1}{x^{2}}\,f'\!\Bigl(\frac1x\Bigr).
$$

（$f(1/x)$ 求导带来因子 $-\dfrac{1}{x^{2}}$，与前面的减号相乘后变成 $+\dfrac{1}{x^{2}}$。）

把 $f'(t)=\dfrac{(t-1)(e^{t}+t)}{t^{2}}$ 中的 $t$ 换成 $\dfrac1x$：

$$
\frac1{x^{2}}f'\!\Bigl(\frac1x\Bigr)=\Bigl(\frac1x-1\Bigr)\Bigl(e^{1/x}+\frac1x\Bigr)
=-\frac{x-1}{x}\Bigl(e^{1/x}+\frac1x\Bigr),
$$

于是

$$
\begin{aligned}
h'(x)&=\frac{(x-1)(e^{x}+x)}{x^{2}}-\frac{x-1}{x}\Bigl(e^{1/x}+\frac1x\Bigr)\\[1mm]
&=\frac{x-1}{x^{2}}\underbrace{\Bigl[e^{x}+x-x\,e^{1/x}-1\Bigr]}_{=:\,m(x)} .
\end{aligned}
$$

**第二步，分析 $m(x)$。** 对 $0<x<1$，

$$
m'(x)=e^{x}+1-e^{1/x}+\frac{e^{1/x}}{x}=e^{x}+1+e^{1/x}\Bigl(\frac1x-1\Bigr)>0,
$$

因为 $\dfrac1x-1>0$ 且 $e^{x}>0,\ e^{1/x}>0$。故 $m$ 在 $(0,1)$ 上严格递增；又

$$
m(1)=e+1-e-1=0\ \Longrightarrow\ m(x)<m(1)=0\qquad(0<x<1).
$$

**第三步，定 $h'$ 的号。** 在 $(0,1)$ 上 $x-1<0$、$m(x)<0$、$x^{2}>0$，故

$$
h'(x)>0\qquad(0<x<1),
$$

即 $h$ 在 $(0,1)$ 上严格递增。又 $h(1)=f(1)-f(1)=0$，所以

$$
h(x)<h(1)=0\qquad(0<x<1),
$$

即 $f(x)<f\!\Bigl(\dfrac1x\Bigr)$。引理证毕。

### 3.4 收尾

对 $x_1\in(0,1)$ 用引理得 $f(x_1)<f\!\Bigl(\dfrac1{x_1}\Bigr)$，结合 $f(x_1)=f(x_2)$：

$$
f(x_2)<f\!\Bigl(\frac1{x_1}\Bigr).
$$

而 $x_2>1$、$\dfrac1{x_1}>1$ 都在 $f$ 的严格递增区间上，故

$$
x_2<\frac1{x_1}\iff \boxed{\,x_{1}x_{2}<1\,}.\qquad\blacksquare
$$

---

## 四、结论

| 问 | 结论 |
|---|---|
| （1） | $a\leqslant e+1$，即 $a\in(-\infty,\ e+1]$ |
| （2） | $x_1x_2<1$ |

**方法小结（极值点偏移）**：① 用导数锁定极值点与两侧单调区间；② 把双零点关系转化为单变量比较
（与 $f(1/x)$ 或 $f(2x_0-x)$ 比较）；③ 构造差函数并用两次求导判定符号；④ 用端点值给出符号基准，
配合严格单调完成结论。

---

## 五、易错点

1. **定义域**：必须写出 $x>0$；忘了定义域，单调区间与"零点两侧"的讨论都会出错。
2. **因式分解**：$-\dfrac1x+1=\dfrac{x-1}{x}$，合并后括号内是 $(e^{x}+x)$，**不是** $(e^{x}+1)$。
3. **复合求导**：$h'(x)=f'(x)+\dfrac{1}{x^{2}}f'\!\Bigl(\dfrac1x\Bigr)$；负号已被吸收，
   写成减号会使后面所有符号反过来。
4. **单调性的使用**：必须点明 $x_2$ 与 $\dfrac1{x_1}$ 都在严格递增区间 $(1,+\infty)$ 上，
   才能把函数值不等式化为自变量不等式。
5. **前提与结论的顺序**：先由 $a>e+1$ 得到 $0<x_1<1<x_2$，不能反过来把待证结论当条件使用。

---

数值复核见 `验证代码.py` 与 `验证结果.txt`（7 组检验全部 PASS），要点：

| $g(x)$ 最小值（三分搜索，不用题解结论） | $=e+1$，偏差 $0$ |

| 12 组 $a>e+1$ 解出两根并验证 | 全部 $f(x_1)=f(x_2)=0$（误差 $<10^{-45}$）且 $x_1x_2<1$ |
| 随机抽查 40 组 $a$ | 反例 $0$ 个 |
| 边界 $a=e+1+10^{-40}$ | $x_1x_2=1-1.8\times10^{-41}$，说明 $1$ 是取不到的上确界 |

左支更陡，故左零点离 $0$ 更近、右零点离 $1$ 更近，于是 $x_2<1/x_1$；当 $a\to(e+1)^{+}$ 时
$x_1x_2\to1^{-}$。

## 四、提示词设计经验

1. **先限定"来源必须可查"**，否则模型容易自编一道题，后续无法核对。
2. **"不能太简单"要落成可判断的标准**（如"需要构造辅助函数""第(2)问不能直接用单调性"），
   否则模型倾向于选常规题。
3. **"做完再检验一遍"要具体到手段**（精度、检验项、输出格式），否则容易得到一句
   "经检验正确"这种没有信息量的自检。
4. **让模型自己列易错点**，能显著提升成稿质量：这些内容往往就是讲 PPT 时最值得讲的点。
5. **排版要求要带"检查动作"**（渲染成图逐页看），否则只是"生成了文件"，不保证好看。
