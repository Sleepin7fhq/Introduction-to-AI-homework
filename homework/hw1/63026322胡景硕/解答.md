# 2026 年新高考Ⅰ卷 数学 第 18 题 · 完整解答

**题目**　椭圆 C：x²/a² + y²/b² = 1（a > b > 0）的左焦点 F(−1, 0)，离心率 1/2。
过 F 且斜率 k > 0 的动直线 l 交 C 于 P、Q 两点，Q 在第三象限，直线 PO 交 C 于另一点 R。

---

## 第（1）问　求 C 的方程

由左焦点 F(−1, 0) 得半焦距 c = |OF| = 1。

由离心率 e = c/a = 1/2，得

```
a = c / e = 1 / (1/2) = 2
```

于是

```
b² = a² − c² = 4 − 1 = 3
```

**所以**

> ### C：x²/4 + y²/3 = 1

---

## 第（2）问

### 预备：直线与椭圆联立

设 l：y = k(x + 1)（k > 0），即 kx − y + k = 0。

代入椭圆方程 3x² + 4y² = 12：

```
3x² + 4k²(x + 1)² = 12
  ⟹  (3 + 4k²)x² + 8k²x + (4k² − 12) = 0
```

其判别式

```
Δ = (8k²)² − 4(3 + 4k²)(4k² − 12) = 144(k² + 1) > 0
```

故 l 与 C 恒有两交点。设 P(x₁, y₁)、Q(x₂, y₂)，由韦达定理

```
x₁ + x₂ = −8k² / (3 + 4k²)
x₁ · x₂ = (4k² − 12) / (3 + 4k²)
```

**两个关键几何事实**

**① R 是 P 关于原点的对称点。**

椭圆中心为原点，直线 PO 过中心，故它与椭圆的另一交点 R 必满足

```
R = −P = (−x₁, −y₁)
```

**② d(R, l) = 2·d(O, l)。**

由 F ∈ l，得

```
d(O, l) = |k·0 − 0 + k| / √(k² + 1) = k / √(k² + 1)
```

又由 R = −P 且 y₁ = k(x₁ + 1)，得

```
d(R, l) = |k(−x₁) − (−y₁) + k| / √(k² + 1)
        = |−k·x₁ + k(x₁ + 1) + k| / √(k² + 1)
        = 2k / √(k² + 1)
        = 2·d(O, l)
```

---

### （i）求 l 的方程

△PQR 与 △PFO 都以 l 上的线段作底边：

```
S(△PQR) = (1/2)·|PQ|·d(R, l)
S(△PFO) = (1/2)·|PF|·d(O, l)
```

两式相除，代入 d(R, l) = 2·d(O, l) 及 S(△PQR) = 3·S(△PFO)：

```
3 = S(△PQR) / S(△PFO) = (|PQ| / |PF|) · 2
  ⟹  |PQ| / |PF| = 3/2          ………… (★)
```

直线 l 上的长度等于横坐标之差乘以弧长因子 √(1 + k²)，故

```
|PQ| = √(1 + k²) · |x₁ − x₂|
|PF| = √(1 + k²) · (x₁ + 1)
```

因 x₁ > x₂（x₁ 是较大的根），有 |x₁ − x₂| = x₁ − x₂。由求根公式

```
x₁ − x₂ = √Δ / (3 + 4k²) = 12√(k² + 1) / (3 + 4k²)

x₁ + 1  = (−4k² + 6√(k² + 1) + 3 + 4k²) / (3 + 4k²)
        = (3 + 6√(k² + 1)) / (3 + 4k²)
```

代入 (★)：

```
12√(k² + 1) / (3 + 6√(k² + 1)) = 3/2
  ⟹  24√(k² + 1) = 9 + 18√(k² + 1)
  ⟹  6√(k² + 1) = 9
  ⟹  √(k² + 1) = 3/2
```

故 k² + 1 = 9/4，k² = 5/4。因 k > 0，

```
k = √5 / 2
```

**所以**

> ### l：y = (√5/2)(x + 1)　即　√5·x − 2y + √5 = 0

---

### （ii）求 tan∠PQR 的最小值

∠PQR 的顶点为 Q，两射线为 QP 与 QR。

**QP 的斜率**即直线 l 的斜率：k(QP) = k。

**QR 的斜率**：

```
k(QR) = (y_R − y_Q) / (x_R − x_Q)
      = (−y₁ − y₂) / (−x₁ − x₂)
      = (y₁ + y₂) / (x₁ + x₂)
```

由 y₁ = k(x₁ + 1)、y₂ = k(x₂ + 1) 得 y₁ + y₂ = k(x₁ + x₂) + 2k，代入韦达定理：

```
y₁ + y₂ = k · (−8k²) / (3 + 4k²) + 2k
        = (−8k³ + 2k(3 + 4k²)) / (3 + 4k²)
        = 6k / (3 + 4k²)
```

于是

```
k(QR) = [6k / (3 + 4k²)] / [−8k² / (3 + 4k²)] = −3 / (4k)
```

**夹角公式。** 因

```
k(QP) · k(QR) = k · (−3/(4k)) = −3/4 ≠ −1
```

两直线不垂直，∠PQR ≠ 90°，且

```
tan∠PQR = | (k(QR) − k(QP)) / (1 + k(QP)·k(QR)) |
         = | (−3/(4k) − k) / (1 − 3/4) |
         = 4 · | 3/(4k) + k |
```

由 k > 0 得 3/(4k) + k > 0，故

```
tan∠PQR = 4 · (3/(4k) + k) = 3/k + 4k
```

**基本不等式。** 因 k > 0，

```
tan∠PQR = 3/k + 4k ≥ 2·√( (3/k) · 4k ) = 2√12 = 4√3
```

等号成立当且仅当 3/k = 4k，即 k² = 3/4，**k = √3/2 > 0**（符合题设）。

**所以**

> ### tan∠PQR 的最小值为 4√3

且在 l 的斜率 k = √3/2 时取得。
