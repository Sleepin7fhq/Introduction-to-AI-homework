## 三、可复现的完整任务提示词（整理版）

> 以下是为了让他人能复现同一份作业而整理的完整提示词，供参考；前两部分为逐字原话。

```
你是一位数学竞赛教练，同时是一名 Python 工程师。请完成下面这道高考题，输出完整解答。

【题目】
2026 年新高考Ⅰ卷 数学 第 18 题（17 分）：
已知椭圆 C：x²/a² + y²/b² = 1（a > b > 0）的左焦点为 F(−1, 0)，离心率为 1/2。
（1）求 C 的方程；
（2）设 O 为坐标原点，过 F 且斜率大于 0 的动直线 l 与 C 交于 P、Q 两点，其中 Q 在
     第三象限，直线 PO 与 C 的另一个交点为 R。
     （i）若 △PQR 的面积是 △PFO 的面积的 3 倍，求 l 的方程；
     （ii）求 tan∠PQR 的最小值。

【任务要求】

1. 原题及来源
   - 写出完整题目原文。
   - 必须联网核实题目与答案，注明出处（试卷名称、年份、题号、链接），
     至少用两个独立来源交叉比对，不得凭记忆编造。
   - 若不同来源对点的字母命名不一致，必须说明采用哪种命名以及为什么。

2. 逐步推理
   - 写出严格完整的推导，每一步都要交代依据，不允许跳步。
   - 关键中间量（联立方程、判别式、韦达定理、面积比转化）都要显式写出。

3. Python 代码验证
   - 只用 Python 3 标准库，不使用第三方库。
   - 独立用数值方法复核解析结论：二分法求根、网格扫描加三分法求极值。
   - 逐点对比数值解与解析解，打印偏差；结果必须能直接运行复现。
   - 数值实验只作佐证，不能替代严格证明。

4. 输出格式
   - 严格结论用清晰的方框或加粗标出，最后给出答案汇总表。
   - 语言用中文，表达简洁、专业、清晰。
   - 排版不要使用 LaTeX 公式，改用纯文本与 Unicode 数学符号（×、÷、√、²、³、
     ≤、≥、≠、△、∠、⟹），保证在任何 Markdown 查看器中都能正常显示。

5. 硬性约束
   - 严禁编造答案，所有结论必须能由推导或代码验证得出。
```
