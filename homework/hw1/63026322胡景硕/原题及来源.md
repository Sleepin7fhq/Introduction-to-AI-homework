# 2026 年新高考Ⅰ卷 数学 第 18 题 · 原题及来源

## 一、原题

> **2026 年普通高等学校招生全国统一考试（新高考全国Ⅰ卷）**
> **数学 · 四、解答题 · 第 18 题（17 分）**

已知椭圆 **C：x²/a² + y²/b² = 1（a > b > 0）** 的左焦点为 **F(−1, 0)**，离心率为 **1/2**。

**（1）** 求 C 的方程；

**（2）** 设 O 为坐标原点，过 F 且斜率大于 0 的动直线 l 与 C 交于 P、Q 两点，其中 Q 在第三象限，直线 PO 与 C 的另一个交点为 R。

　　**（i）** 若 △PQR 的面积是 △PFO 的面积的 3 倍，求 l 的方程；

　　**（ii）** 求 tan∠PQR 的最小值。

### 核对说明

**1. 结构一致。** 三处独立来源对「题号 18、分值 17 分、题型（椭圆/圆锥曲线）、三问结构」的描述完全一致。

**2. 公式来源。** 部分网站在**未登录状态下会剥离公式**（只留文字骨架）。本次核对实际验证：21 世纪教育网与组卷网的公开页面里，公式位置全是空白，HTML 源码中也不含公式文本或公式图片。故本题面采自公式完整的「良师宝」条目，并与其文字骨架逐字比对，确认结构一致。

**3. 字母命名的考据（重要）。** 不同网站对同一点的字母命名不同：21 世纪教育网用 **M, N, P**，良师宝用 **P, Q, R**，数学内容相同。本文统一采用 **P, Q, R** 命名，理由是：

- 按 P, Q, R 解读（P 为直线与椭圆的上方交点，Q 在第三象限，R 为 P 的对径点），第（2)(i) 问的面积条件**有解**：k = √5/2。
- 若按另一种命名解读（把面积条件里的三角形换成含 Q 的那组），会导出 √(1+k²) = 3/14 < 1，与 √(1+k²) ≥ 1 矛盾，**无解**。

所以 P, Q, R 的解读是唯一自洽的。

**4. 独立复核。** 第（2)(ii) 问公开解答只给结论，本目录的 `解答.md` 给出完整严格推导，并由 `验证代码.py` 独立数值复核（仅用 Python 3 标准库）。

## 三、考点

- 椭圆的标准方程与几何性质（焦点、离心率、中心对称性）
- 直线与椭圆的位置关系、韦达定理
- 三角形面积的转化（同底比高 / 点到直线距离）
- 两直线夹角的正切公式与基本不等式求最值
