## 重新生成

依赖：Python 3 + `python-pptx`（`pip install python-pptx`）。

```bash
python build_math_deck.py
```

- 脚本会自动读取 `assets/formulas/meta.json` 与同名 PNG 落位；**没有 Node 环境也能直接重跑**，会复用已有公式图。
- 若修改了脚本顶部 `FORMULAS` 里的公式，需要恢复 Node 依赖后重排公式：

```bash
cd tools/math
npm install          # mathjax-full + @resvg/resvg-js
cd ../..
python build_math_deck.py
```

- 预览（需要 LibreOffice）：`bash preview_math.sh`。

## 数学结论与核验

- $\int_0^1|f|^2dx=N$：正交性筛出 N 个对角项（与加性唯一性无关）。
- $\int_0^1|f|^4dx=2N^2-N$：有序四元组计数，对角 $N$ + 非对角 $2N(N-1)$；等价地 $4\binom N2+N$。
- 边界与反例核验：$N=1\Rightarrow1$；$S=\{0,1\}\Rightarrow6$；$S=\{0,1,3\}\Rightarrow15$；非 Sidon 的 $S=\{0,1,2\}$ 得 $19>15$。
- 第 (2) 问：$N\le I^{2/3}(2N^2-N)^{1/3}\Rightarrow I\ge N/\sqrt{2N-1}\ge\sqrt{N/2}\ge 1/(2\sqrt N)$，每一步在页面上标注依据。
