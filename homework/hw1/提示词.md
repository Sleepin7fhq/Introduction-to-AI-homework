# 提示词

本文件记录本次 Demo 实践中**实际使用**的提示词，并给出可复用的提示词模板。
说明：题目求解、证明与数值验证均由 dsh 完成，提示词的作用是限定来源、难度、
要求"不照抄答案"以及强制"做完再自检一遍"。

## 一、用户提示词（原文照录）

### 1. 主任务提示词

```text
在网上寻找一道数学题，来源，可以是高等数学、线性代数的难题、高考压轴题、奥数竞赛数学猜想等，
并把它做完不能太简单，要有一定的过程思维性强，答案不能出错，做完以后自己再检验一遍
```

要点拆解：

| 约束 | 作用 |
|---|---|
| "在网上寻找" | 要求真实的题源（不许自编），并给出可核查的出处 |
| "高考压轴题 / 高数 / 线代 / 奥数 / 猜想" | 限定难度区间与知识范围 |
| "不能太简单，过程思维性强" | 排除套公式题，要求有化归或构造的一步 |
| "答案不能出错" | 要求严格证明，而不是"看起来对" |
| "做完以后自己再检验一遍" | 强制二次验证（本题用 60 位精度数值实验） |

## 二、任务分解提示词（本次实际执行的关键指令）

### 2.1 联网检索选题

```text
用联网搜索在高考真题库中定位"2022 年全国甲卷理科数学第 21 题"，核对题干、题号、分值，
给出至少两个可访问的来源链接；确认题面一致后再采用。
```

实际使用的检索词（按序）：

```text
2022年高考全国甲卷理科数学第21题 f(x)=e^x/x - ln x + x - a 两个零点 证明 x1x2<1
2022 全国甲卷 21题 已知函数 f(x)=e^x/x-ln x+x-a 若f(x)≥0 求a的取值范围
2022年普通高等学校招生全国统一考试甲卷理科数学 21 导数 极值点偏移 x1x2<1
```

### 2.2 独立求解（禁止照抄）

```text
不要照抄网上的标准答案：先自己求导、判断单调性与极值，分析两个零点的位置，
再想办法把"两个零点之积小于 1"化归为一个单变量函数不等式，并给出可检验的构造。
每一步都要能说明理由（定义域、严格单调的用法、符号判定）。
```

### 2.3 强制自检

```text
写一个只用标准库的 Python 脚本，用 60 位十进制精度独立复核：
(1) 极值是否为 e+1；(2) 导数解析式与中心差分的偏差；
(3) 核心引理 h(x)=g(x)-g(1/x)<0 在 (0,1) 上的符号；
(4) 对多组 a>e+1 真解出两个零点并检查 x1x2<1，另做随机抽查；
(5) 边界情形 a=e+1、a=e+1+1e-40。
输出每个检验项的 PASS/FAIL 与具体数值。
```

### 2.4 数学可视化

```text
用真实函数值绘制插图：画出曲线 y=e^x/x-ln x+x、水平线 y=a、两个零点与极小值点，
并用区间双箭头标出 x2 < 1/x1；配色与 PPT 模板一致（深绿/明黄/蓝/橙）。
```

### 2.5 套模板排版

```text
在东南大学 PPT 模板基础上重排：沿用模板的版式（封面/章节页/内容页/结束页）与主题色
（#445437 / #FFCC00 / #2872A1 / #EA6C00），把内容整理成"选题→证明→自检"三段；
```

## 三、可复用的提示词模板

### 模板 A：选题

```text
在网上找一道【高等数学/线性代数/高考压轴/奥数竞赛】的难题，要求：
1. 必须给出可访问的来源链接，并核对题面；
2. 难度不低于【某标准】，需要化归、构造或反证等非套路步骤；
3. 答案唯一或结论明确，便于事后数值验证。
给我 3 个候选，并说明每个的难点与验证方式，再选一个开始做。
```

### 模板 B：求解

```text
不照抄任何现成答案，独立完成【题目】：
- 先写定义域与关键观察；
- 给出完整推导（每一步标注依据）；
- 单独列出易错点（符号、因式分解、复合求导、单调性的使用条件）。
```

### 模板 C：自检

```text
写脚本用【N 位精度】独立复核上面的每一步：
① 关键恒等式与数值导数比对；② 极值与临界参数；③ 结论不等式在多组参数下成立；
④ 边界与极限情形；⑤ 随机抽查。输出逐项 PASS/FAIL 与数值。
注意：数值实验只用于复核，不能替代证明。
```

### 模板 D：整理成稿

```text
把上面的过程整理成【PPT/文档】，结构为：题目与来源 → 思路与方法 → 完整推导 →
数值验证 → 易错点 → 结论与方法迁移；要求逻辑层次清晰、公式排版规范、配色统一。
```

## 四、提示词设计经验

1. **先限定"来源必须可查"**，否则模型容易自编一道题，后续无法核对。
2. **"不能太简单"要落成可判断的标准**（如"需要构造辅助函数""第(2)问不能直接用单调性"），
   否则模型倾向于选常规题。
3. **"做完再检验一遍"要具体到手段**（精度、检验项、输出格式），否则容易得到一句
   "经检验正确"这种没有信息量的自检。
4. **让模型自己列易错点**，能显著提升成稿质量：这些内容往往就是讲 PPT 时最值得讲的点。
5. **排版要求要带"检查动作"**（渲染成图逐页看），否则只是"生成了文件"，不保证好看。
