# 悬链线数学物理研究项目

此项目的原题为自设问题：均匀、完全柔软、不可伸长的绳索在均匀重力场中，两端固定时的静态形状。
## 复现

Python 3.12，依赖 numpy scipy matplotlib。原运行版本：NumPy 2.3.5、SciPy 1.17.0、Matplotlib 3.10.8。

在解压目录运行：

```bash
python build/research.py
```

程序会重新生成 build/results.json、build/curve.csv 以及 build/assets 中的科学图表。图表同时保留 PNG 与 SVG。运行不同版本优化器时，末位数值和迭代次数可能有小变化。初始根区间适用于当前研究参数，不声称是任意极端参数的通用稳健求解器。

build/content.py 保存演示文稿完整中文内容、说明及 LaTeX 公式源，可用 matplotlib 再生成复杂公式高清图。build/deck.mjs 使用 JavaScript Artifact Tool 创建可编辑正文、表格、示意图、流程图和 PPTX，需要原 ChatGPT Work 的 Artifact Tool 及演示文稿验证工具环境。其代码中的运行环境路径需按使用环境调整。

## 模型及必要前提

取 x 水平向右、y 向上。A=(x1,y1)、B=(x2,y2)，D=x2-x1>0，Δ=y2-y1，绳长 L，线密度ρ>0，g>0，w=ρg。按材料弧长 s∈[0,L] 描述位置 r(s)，不可伸长意味着 |r′|=1 几乎处处。端点固定且无接触、无弹性伸长、无抗弯刚度。张力沿切线。

总势能 U=w∫_0^L y(s)ds。图像曲线的弧长 S[y]=∫√(1+y′²)dx，故 U[y]=w∫y√(1+y′²)dx，条件为固定两端且 S[y]=L。图像类用于导出候选，最终全局比较允许任意 AC 单位速率平面曲线，包括回折和自交。

均匀绳的质量按实际弧长均匀，不能把势能写成 w∫y dx。

## 约束变分的完整关键步骤

采用 Jλ=U+λ(S−L)，F=(wy+λ)q，p=y′，q=√(1+p²)。对端点为零的变分η，

δJ=∫[wqη+(wy+λ)(p/q)η′]dx。

分部积分消掉边界项，得 wq−d[(wy+λ)p/q]/dx=0。利用 d(p/q)/dx=y″/q³，展开得到

(wy+λ)y″=w(1+y′²)。

若 δS 对所有端点固定η恒为零，则 d(p/q)/dx=0，y′恒定且 S=d=√(D²+Δ²)。因此 L>d 时约束导数非零，等式约束乘子法正则。λ是一个全局常数，不是任意函数。

设 z=y+λ/w，正张力物理解取z>0，则 zz″=1+z′²。在z单调区间用 p=z′ 看作z函数：z p dp/dz=1+p²，积分得到 1+p²=z²/a²，a>0。这个恒等式在最低点连续延拓。代回原方程得 z″=z/a²。解为z=Ae^{x/a}+Be^{−x/a}，恒等式要求4AB=a²。z>0意味着A,B>0，可写A=(a/2)e^{−x0/a}、B=(a/2)e^{x0/a}，因此

y=a cosh((x−x0)/a)+c，c=−λ/w。

E-L 方程也允许倒悬的负z驻值分支。柔绳只能拉不能压，独立静力学与下面的全局证明选择正张力分支。

## 常数确定、存在性及唯一性

xm=(x1+x2)/2，u=D/(2a)>0，v=(xm−x0)/a。端点差高与长度给出

Δ=2a sinh(u)sinh(v)，L=2a sinh(u)cosh(v)。

所以 v=artanh(Δ/L)，sinh(u)/u=√(L²−Δ²)/D。

函数sinh(u)/u从1严格增加到无穷，因其导数分子h(u)=u cosh(u)−sinh(u)满足h(0)=0且h′(u)=u sinh(u)>0。

L>d时右侧>1，故u、a、x0、c唯一。x0=xm−a artanh(Δ/L)，c=y1−a cosh((x1−x0)/a)。L<d时不可行。L=d时只有直线，约束退化，D>0且w>0时没有有限张力的柔绳静态解。D=0的竖直情形不在此次推导范围内。x0可能在端点区间之外。

## 独立静力学方法

沿A到B定义Q=Tt=(H,V)。微元左端受−Q(s)，右端受Q(s+ds)，重力(0,−w ds)，所以Q′=(0,w)，H恒定且正。由切线方向V=Hy′，得Hy″=w√(1+y′²)。令a=H/w，则dp/√(1+p²)=dx/a，asinh(p)=(x−x0)/a，积分得同一悬链线。没有使用能量泛函。

T=H√(1+y′²)=wa cosh((x−x0)/a)=wy+λ。此等式给出z>0的物理依据。支持力分别为−Q(0)和Q(L)，其合力为(0,wL)，与整绳重量平衡。

## 全局极小性证明

令r*为上述悬链线的单位速率参数化，Q*=T*t*且Q*′=(0,w)。任取同端点、同L且|r′|=1的AC曲线，分部积分得

U[r]−U[r*]=∫Q*′·(r−r*)ds
=−∫Q*·(r′−t*)ds
=∫T*(1−t*·r′)ds≥0。

端点差为零，最后一步由T*>0及两个单位向量点积≤1得到。等号仅在r′=t*几乎处处成立，同端点进一步给出r=r*。这证明唯一全局最小值，覆盖非图像曲线，不是仅凭E-L条件作出的推断。

甚至放宽成|r′|≤1，此证书仍然有效。对光滑可行曲线族 rε=r*+εh+O(ε²)，由单位向量恒等式1−t*·rε′=|rε′−t*|²/2，得到

U[rε]−U[r*]=(ε²/2)∫T*|h′|²ds+o(ε²)。

端点固定非零扰动使此项严格为正。静态稳定性不意味着无阻尼理想系统会自动停止。

## Beltrami 恒等式及乘子意义

F不显含x。沿E-L解，d(F−pF_p)/dx=F_x=0，故(wy+λ)/√(1+y′²)=C。物理解C=wa=H，即水平内力。F显含y，不能宣称F_p恒定。

采用U+λ(S−L)时λ=−wc，且固定端点下最优值函数的包络导数dU*/dL=−λ。改用U−μ(S−L)则μ=−λ，T=wy−μ。高度坐标加b时λ减wb，而T,H不变。λ有力的量纲，但依赖势能零点，不能把它无条件等同于水平张力。

## 实际运行结果

输入：A=(0,0)m，B=(10,2)m，L=12m，ρ=0.8kg/m，g=9.81m/s²。可理解为两支架分别在相对于地面的3m和5m高度，采用左支架高度作为零点，最低点距离地面约1.107m；研究未加入接地约束。

输出：a=4.894719253946406m，x0=4.176531432495869m，c=−6.787348634985433m。最低点y=−1.8926293810390264m。H=38.4137567049714N，T(A)=53.26711208736568N，T(B)=68.96311208736567N。U=−70.26003698477611J。

独立射击从H=40N、V0=−40N起始，积分r′=(H,V0+ws)/√(H²+(V0+ws)²)，对H使用log参数化，并由两端闭合求解。终点最大残差5.33×10⁻¹⁵m，501个弧长采样点最大位置差5.69×10⁻¹¹m。

离散优化令N个链节等长，每个链节长度严格为L/N，内部节点为未知量。精确直链节势能为w(L/N)[(y0+yN)/2+∑内部yj]。初始化在解析曲线上增加0.15 sin(πs/L)的竖直扰动，再用SLSQP实际优化。N=20/40/80均报告成功，最大节点误差分别3.635/0.909/0.227mm，显示约二阶收敛。链长残差约10⁻¹³至10⁻¹⁴m。KKT残差约10⁻⁶，完整值保留在results.json。

当前双精度运算中的零残差只意味着浮点运算返回零，不代表无限精度认证。三次网格结果支持观察到的二阶趋势，不替代理论收敛阶证明。数值优化不是全局最小性的证明，解析能量证书才是。
